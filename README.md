# CP Sync

Олимпиадные задачи из CLion на всех ваших устройствах, а тесты запускаются прямо с телефона.

* **Синхронизация CLion.** Сохранили файл на одном компьютере — он уже на другом. Проект, начатый дома, открывается в школе одним нажатием.
* **Тесты с телефона.** Выбираете задачу, вводите тесты (и, если хотите, правильные ответы) и видите вердикты **AC / WA / TLE / MLE / RE**, время и память. Код компилируется **на сервере**, так что ноутбук может быть выключен.
* **Правка кода где угодно.** Можно исправить решение прямо в телефоне, и изменения сами придут в CLion.
* **Никаких токенов и адресов.** Обычная регистрация (логин и пароль). Телефон подключается по QR-коду, а плагин скачивается с сайта уже настроенным.

---

## Как пользоваться

### Телефон (и любой компьютер)

1. Откройте сайт CP Sync в Safari и зарегистрируйтесь.
2. Нажмите «Поделиться» → **«На экран „Домой“»**. CP Sync будет открываться как обычное приложение.

Внутри: **Проекты → задача → Тесты**. Введите входные данные, при желании ожидаемый ответ, и нажмите **«Запустить»**. На вкладке **«Код»** можно посмотреть и исправить решение. Тесты сохраняются в аккаунте и видны на всех устройствах.

### CLion (на каждом компьютере)

1. На сайте: **Аккаунт → Скачать плагин**. В плагин уже встроен адрес вашего сервера.
2. CLion → **Settings → Plugins → ⚙ → Install Plugin from Disk…** → выберите скачанный zip (распаковывать не нужно). Нужен CLion 2025.1 или новее.
3. Справа появится окно **CP Sync** → **«Войти»** → логин и пароль. Можно и без пароля: на сайте нажмите «Войти без пароля» и вставьте ссылку.
4. Откройте проект и нажмите **«Поделиться проектом»** (кнопка в окне CP Sync или Tools → CP Sync).
5. На втором компьютере нажмите **«Открыть проект с сервера»**: проект скачается в `~/CPSync/<имя>` и откроется.

Дальше всё происходит само: сохранили файл → через ~1,5 с он на сервере → другие компьютеры получают его за секунду. Кнопка 🔄 на верхней панели CLion запускает синхронизацию вручную. **«Подключить телефон»** в окне CP Sync показывает QR-код: наведите камеру iPhone, и вход выполнится сам.

Не синхронизируются служебные папки и файлы: `.idea`, `.git`, `cmake-build-*`, `build`, бинарники и файлы больше 1 МБ. Если файл изменили на двух устройствах одновременно, останется более новая версия, а вторая сохранится в `<проект>/.cpsync/conflicts/`. Удалённые файлы попадают в `.cpsync/trash/`, так что ничего не теряется.

### Как запускается код

| | |
|---|---|
| Языки | C++ (g++ 13; C++17 / C++20 / C++23), C (C17), Python 3.12 |
| Флаги | `-O2 -DONLINE_JUDGE`, поэтому `#ifndef ONLINE_JUDGE freopen(...)` не мешает |
| Ограничения | время 0,5–10 с, память 64–512 МБ (выбираются в телефоне), стек = лимит памяти (глубокая рекурсия работает) |
| Проверка | сравнение по словам: пробелы и переводы строк не важны, дробные числа сравниваются с точностью 1e-6 |
| `#include "file.h"` | работает: рядом с решением лежат все файлы проекта |

Каждый запуск идёт в отдельном изолированном контейнере: без сети, без доступа к чужим данным, с лимитами процессов и памяти.

## Установка сервера (один раз, около 10 минут)

Нужен VPS с Ubuntu 24.04 (или 22.04 / Debian 12), 2 ГБ памяти и публичным IPv4. Подойдёт любой хостинг, например Hetzner Cloud: тариф CX22 стоит около 4 € в месяц.

**Вариант без командной строки (Hetzner и другие хостинги с полем «Cloud config / User data»):**

1. Создайте сервер: образ **Ubuntu 24.04**, тариф **CX22**, включите **публичный IPv4**.
2. В поле **Cloud config** вставьте содержимое файла [`deploy/cloud-init.yml`](deploy/cloud-init.yml):
   ```yaml
   #cloud-config
   runcmd:
     - curl -fsSL https://raw.githubusercontent.com/Nmk102/cpsync/main/deploy/install.sh | bash
   ```
3. Через 3–5 минут откройте `https://<IP-адрес-через-дефисы>.sslip.io`. Например, для IP `5.75.123.45` это `https://5-75-123-45.sslip.io`.
4. **Первый, кто зарегистрируется, станет администратором.** Зарегистрируйтесь сразу.

**Вариант через SSH (любой хостинг):**

```bash
curl -fsSL https://raw.githubusercontent.com/Nmk102/cpsync/main/deploy/install.sh | sudo bash
```

Скрипт сам ставит Docker, собирает песочницу, запускает сайт и получает HTTPS-сертификат. В конце он печатает адрес.

### Настройки и обслуживание

| Что | Как |
|---|---|
| Обновить до последней версии | ещё раз выполнить команду установки (данные сохраняются) |
| Свой домен | направить A-запись на сервер и выполнить `curl … \| sudo CPSYNC_DOMAIN=cpsync.example.com bash` |
| Закрыть регистрацию посторонним | `curl … \| sudo CPSYNC_REGISTRATION=closed bash` |
| Список пользователей | `cd /opt/cpsync && docker compose exec app python -m cpsync.admin users` |
| Сбросить пароль | `… python -m cpsync.admin reset-password <логин>` (напечатает новый пароль) |
| Журнал | `cd /opt/cpsync && docker compose logs -f` |
| Резервные копии | все данные лежат в `/var/lib/cpsync`; у Hetzner можно включить «Backups» (+20 % к цене) |

Если сервер нужно разместить из другого репозитория, задайте `CPSYNC_REPO=пользователь/репозиторий`.

## Для разработчика

```
server/cpsync/      сервер (Python 3.10+, из зависимостей только segno для QR-кодов)
server/sandbox/     образ песочницы и исполнитель тестов (runner.py)
server/web/         веб-приложение (PWA, без сборки)
plugin/             плагин CLion (Kotlin, IntelliJ Platform)
dist/               собранный плагин, который раздаёт сайт (обновляется CI)
deploy/             установка на VPS: install.sh, Caddyfile, cloud-init
docker-compose.yml  app + Caddy (HTTPS)
tests/              интеграционные тесты сервера
```

* Запуск сервера локально: `pip install segno && PYTHONPATH=server python3 -m cpsync --port 8080`. Без Docker код запускается **без изоляции**, так можно делать только для разработки.
* Тесты сервера: `python3 tests/test_server.py` (с Docker-песочницей: `CPSYNC_SANDBOX=docker …`).
* Плагин: `cd plugin && ./gradlew buildPlugin test`. Проверка совместимости с CLion: `./gradlew verifyPlugin`.
