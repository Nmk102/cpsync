## 1. Позиционная система

В системе с основанием $q$ (*base q*) используются цифры $0, 1, \ldots, q - 1$, и вклад цифры зависит от её **позиции**:
$$\overline{a_ka_{k-1}\ldots a_1a_0}_{\,q} = a_k q^k + \cdots + a_1q + a_0.$$
В шестнадцатеричной (*hexadecimal*) после 9 идут буквы: A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.

:::tip Полезные степени
$2^{10} = 1024$, $2^{8} = 256$, $2^{16} = 65\,536$; $8^2 = 64$, $8^3 = 512$; $16^2 = 256$, $16^3 = 4096$.
:::

## 2. Перевод в десятичную

Раскладываем по степеням основания:
$$101101_2 = 32 + 8 + 4 + 1 = 45,\qquad 372_8 = 3\cdot64 + 7\cdot8 + 2 = 250,\qquad 1\text{A}3_{16} = 256 + 10\cdot16 + 3 = 419.$$

**Схема Горнера** — быстрее в уме: читаем цифры слева направо, каждый раз «умножить на основание и прибавить цифру».
$101101_2$: $1 \to 2 \to 5 \to 11 \to 22 \to 45$.

**Дробная часть** — отрицательные степени: $0{,}101_2 = \frac12 + \frac18 = 0{,}625$.

## 3. Перевод из десятичной

:::key Целая часть — деление с остатком
Делим на $q$, пока не получим 0, и выписываем остатки **снизу вверх** (последний остаток — старшая цифра).
:::

$45$ в двоичную: $45 = 2\cdot22 + 1$, $22 = 2\cdot11 + 0$, $11 = 2\cdot5 + 1$, $5 = 2\cdot2 + 1$, $2 = 2\cdot1 + 0$, $1 = 2\cdot0 + 1$ ⇒ снизу вверх: $101101_2$ ✓.
$419$ в шестнадцатеричную: $419 = 16\cdot26 + 3$, $26 = 16\cdot1 + 10$, $1 = 16\cdot0 + 1$ ⇒ $1\text{A}3_{16}$ ✓.

:::key Дробная часть — умножение
Умножаем дробную часть на $q$; целая часть результата — очередная цифра (**сверху вниз**); продолжаем с дробной частью.
:::

$0{,}625$ в двоичную: $0{,}625\cdot2 = 1{,}25$ → 1; $0{,}25\cdot2 = 0{,}5$ → 0; $0{,}5\cdot2 = 1{,}0$ → 1 ⇒ $0{,}101_2$.
$0{,}1$ в двоичную: $0{,}2 \to 0$, $0{,}4 \to 0$, $0{,}8 \to 0$, $1{,}6 \to 1$, $1{,}2 \to 1$, $0{,}4 \to 0$, … — **период**: $0{,}0\overline{0011}_2$. Поэтому в программах `0.1 + 0.2 != 0.3`: число 0,1 нельзя точно записать в двоичной системе.

## 4. Быстрый перевод 2 ↔ 8 ↔ 16

$8 = 2^3$ и $16 = 2^4$, поэтому каждая восьмеричная цифра — ровно 3 бита, шестнадцатеричная — 4 бита. Группируем **от запятой**: целую часть — справа налево, дробную — слева направо, недостающие разряды дополняем нулями.

$$1101011010_2 = \underbrace{001}_{1}\,\underbrace{101}_{5}\,\underbrace{011}_{3}\,\underbrace{010}_{2} = 1532_8 = \underbrace{0011}_{3}\,\underbrace{0101}_{5}\,\underbrace{1010}_{\text{A}} = 35\text{A}_{16}.$$

**8 ↔ 16 — через двоичную**: $1532_8 \to 1101011010_2 \to 35\text{A}_{16}$.

## 5. Арифметика в двоичной

Сложение — столбиком, как в десятичной, только $1 + 1 = 10_2$ (пишем 0, переносим 1), $1 + 1 + 1 = 11_2$.
```
  1011 0110      (182)
+ 0110 1101      (109)
-----------
1 0010 0011      (291)
```
Вычитание — с займом: $10_2 - 1 = 1$. Умножение — сдвиги и сложения: умножить на $2^k$ = дописать $k$ нулей (в коде `x << k`), разделить нацело на $2^k$ = отбросить $k$ младших битов (`x >> k`).

## 6. Отрицательные числа: дополнительный код

:::def Дополнительный код (*two's complement*) на $n$ битах
Неотрицательные числа $0 \ldots 2^{n-1} - 1$ записываются как обычно (старший бит 0). Отрицательное $-x$ записывается как $2^n - x$ (старший бит 1).
**Быстрый способ:** записать $x$, **инвертировать** все биты и **прибавить 1**.
:::

8 бит: $5 = 00000101$ ⇒ инверсия $11111010$ ⇒ $+1$ ⇒ $11111011 = -5$.
Обратно: $11111011$ ⇒ инверсия $00000100$ ⇒ $+1$ ⇒ $00000101 = 5$, значит, исходное число $-5$.

**Диапазон $n$ бит со знаком:** $-2^{n-1} \ldots 2^{n-1} - 1$: для 8 бит $-128 \ldots 127$, для 32 бит $-2\,147\,483\,648 \ldots 2\,147\,483\,647$ (`int` в C++).

:::key Зачем так сложно
В дополнительном коде **вычитание = сложение**: $7 - 5 = 7 + (-5)$: $00000111 + 11111011 = 1\,00000010$ — девятый бит отбрасываем, получаем $2$ ✓. Процессору не нужен отдельный «вычитатель».
:::

:::warn Переполнение (*overflow*)
$127 + 1$ в 8 битах: $01111111 + 1 = 10000000 = -128$. В C++ переполнение `int` — источник ошибок в олимпиадных задачах: если ответ может превысить $2\cdot10^9$, нужен `long long`. В Python целые числа неограниченны, переполнения нет (но в NumPy — есть, см. конспект про NumPy).
:::

## 7. Единицы информации

1 байт = 8 бит. $n$ бит кодируют $2^n$ разных значений. Обратная задача: для $N$ вариантов нужно $\lceil\log_2N\rceil$ бит (например, 100 вариантов → 7 бит, так как $2^6 = 64 < 100 \le 128 = 2^7$).
1 КиБ = 1024 байта, 1 МиБ = $2^{20}$ байт (в маркетинге часто 1 КБ = 1000 байт).

## 8. Python

```python
int("101101", 2), int("372", 8), int("1A3", 16)   # 45 250 419
bin(45), oct(250), hex(419)                       # '0b101101' '0o372' '0x1a3'
format(45, "b"), format(45, "08b"), format(419, "X")   # '101101' '00101101' '1A3'
format(-5 & 0xFF, "08b")                          # '11111011' — доп. код на 8 битах

def to_base(n, q):
    """Перевод неотрицательного n в систему с основанием q (2 ≤ q ≤ 36)."""
    digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    if n == 0:
        return "0"
    s = ""
    while n > 0:
        s = digits[n % q] + s      # остатки — в начало строки (снизу вверх)
        n //= q
    return s

print(to_base(419, 16), to_base(45, 2), to_base(2024, 7))   # 1A3 101101 5621
```

## 9. Проверь себя

:::task 1. Переведите $2026$ в двоичную, восьмеричную и шестнадцатеричную.
:::answer
$2026 = 1024 + 512 + 256 + 128 + 64 + 32 + 8 + 2 = 11111101010_2$. Группы по 3: $011\,111\,101\,010 = 3752_8$. Группы по 4: $0111\,1110\,1010 = 7\text{EA}_{16}$.
:::
:::

:::task 2. Сколько единиц в двоичной записи числа $2^{10} - 1$? А $2^{10} + 2^5 - 1$?
:::answer
$2^{10} - 1 = 1111111111_2$ — 10 единиц. $2^{10} + 2^5 - 1 = 2^{10} + (2^5 - 1) = 10000011111_2$ — 6 единиц.
:::
:::

:::task 3. Запишите $-100$ в 8-битном дополнительном коде.
:::answer
$100 = 01100100$ ⇒ инверсия $10011011$ ⇒ $+1$ ⇒ $10011100$. Проверка: $256 - 100 = 156 = 10011100_2$ ✓.
:::
:::

:::task 4. В какой системе счисления $25 + 17 = 43$?
:::answer
$(2q + 5) + (q + 7) = 4q + 3$ ⇒ $3q + 12 = 4q + 3$ ⇒ $q = 9$. Проверка в 9-ричной: $5 + 7 = 12 = 13_9$, пишем 3, перенос 1; $2 + 1 + 1 = 4$ ⇒ $43_9$ ✓ (цифра 7 допустима при $q = 9$).
:::
:::

:::task 5. Переведите $0{,}375$ и $13{,}6$ в двоичную.
:::answer
$0{,}375$: $0{,}75 \to 0$, $1{,}5 \to 1$, $1{,}0 \to 1$ ⇒ $0{,}011_2$.
$13{,}6 = 1101_2 + 0{,}6$: $1{,}2 \to 1$, $0{,}4 \to 0$, $0{,}8 \to 0$, $1{,}6 \to 1$, $1{,}2 \to 1$, … ⇒ $1101{,}1\overline{0011}_2$ (бесконечная периодическая дробь).
:::
:::
