Листок *TLF10 — Equations with Parameters*. Задачи 19 и 20 — домашнее задание (IGCSE Additional Maths). Сначала попробуйте сами, потом открывайте подсказку и решение. Все ответы дополнительно проверены численно: для каждого промежутка значений параметра посчитано количество решений.

:::tip Три приёма, на которых держится весь листок
1. **Особый случай старшего коэффициента**: если перед $x^2$ стоит параметр, отдельно разберите, когда он равен 0.
2. **Замена** $t = x^2$, $t = \sin x$, $t = \cos x$ — и аккуратный **подсчёт**: сколько $x$ даёт каждое $t$.
3. **Графический метод**: выразите параметр $a = g(x)$ или $a = h(t)$ и двигайте горизонтальную прямую $y = a$.
:::

## Подсчёт решений после замены (шпаргалка)

| Замена | Значение $t$ | Сколько $x$ |
|---|---|---|
| $t = x^2$ | $t > 0$ | 2 ($\pm\sqrt t$) |
| | $t = 0$ | 1 |
| | $t < 0$ | 0 |
| $t = \sin x$, $x \in [0;\,2\pi)$ | $-1 < t < 1$ | 2 (при $t = 0$: $x = 0,\ \pi$) |
| | $t = \pm 1$ | 1 |
| $t = \cos x$, $x \in [0;\,2\pi)$ | $-1 < t < 1$ | 2 |
| | $t = 1$ (только $x = 0$), $t = -1$ (только $x = \pi$) | 1 |

Внимательно смотрите на **границы промежутка**: $[0;\,2\pi]$ и $[0;\,2\pi)$ дают разный ответ для $\sin x = 0$ (три решения или два).

## Задача 1
> При каких $a$ уравнение $(a-2)x^2 - 2ax + a + 2 = 0$ имеет ровно одно решение?

:::solution
**$a = 2$:** $-4x + 4 = 0 \Rightarrow x = 1$ — одно решение. ✓

**$a \ne 2$:** $\dfrac D4 = a^2 - (a-2)(a+2) = a^2 - a^2 + 4 = 4 > 0$ — всегда **два** корня.

**Ответ:** $a = 2$.
:::

## Задача 2
> При каких $a$ уравнение $\dfrac{x^2 - 2ax + 1}{x - 1} = 0$ имеет ровно одно решение?

:::hint
Числитель равен нулю, знаменатель — нет. Когда $x = 1$ является корнем числителя? Заметьте: произведение корней числителя равно 1.
:::

:::solution
Нужно $x^2 - 2ax + 1 = 0$, $x \ne 1$. Число $1$ — корень числителя, если $1 - 2a + 1 = 0$, то есть $a = 1$.

$\dfrac D4 = a^2 - 1$.
- $|a| > 1$: два различных корня, причём ни один не равен 1 (это было бы только при $a = 1$) → **два** решения.
- $a = 1$: двойной корень $x = 1$ — выколот → **нет** решений.
- $a = -1$: двойной корень $x = -1$ → **одно** решение. ✓
- $|a| < 1$: корней нет.

**Ответ:** $a = -1$.
:::

## Задача 3
> Сколько решений имеет $|x^2 - 2x - 3| = a$ в зависимости от $a$?

:::solution
$x^2 - 2x - 3 = (x-3)(x+1)$, вершина $(1;\,-4)$. После модуля часть под осью отражается вверх — получается «горка» высотой 4 над отрезком $[-1;\,3]$.

| $a$ | решений |
|---|---|
| $a < 0$ | 0 |
| $a = 0$ | 2 ($x = -1;\ 3$) |
| $0 < a < 4$ | 4 |
| $a = 4$ | 3 |
| $a > 4$ | 2 |
:::

## Задача 4
> При каких $a$ уравнение $\sqrt{x + 2} = x - a$ имеет ровно одно решение?

:::hint
Замена $t = \sqrt{x+2} \ge 0$. Каждому $t \ge 0$ соответствует ровно один $x = t^2 - 2$.
:::

:::solution
Пусть $t = \sqrt{x + 2} \ge 0$, тогда $x = t^2 - 2$ и уравнение: $t = t^2 - 2 - a$, то есть
$$a = t^2 - t - 2 = g(t), \qquad t \ge 0.$$
Каждому $t \ge 0$ — ровно один $x$, поэтому считаем решения $g(t) = a$ при $t \ge 0$.

$g(0) = -2$, вершина при $t = \tfrac12$: $g\left(\tfrac12\right) = -\tfrac94$, дальше $g$ растёт до $+\infty$.
- $a < -\tfrac94$: нет решений;
- $a = -\tfrac94$: одно ($t = \tfrac12$);
- $-\tfrac94 < a \le -2$: два (одно $t \in [0;\,\tfrac12)$, другое $t \in (\tfrac12;\,1]$);
- $a > -2$: одно ($t > 1$).

**Ответ:** $a = -\tfrac94$ или $a > -2$.
:::

## Задача 5
> При каких $a$ оба корня $x^2 - 2ax + a + 2 = 0$ действительны, различны и больше 1?

:::solution
$f(x) = x^2 - 2ax + a + 2$, ветви вверх, $x_0 = a$. Условия:
1. $\dfrac D4 = a^2 - a - 2 = (a-2)(a+1) > 0 \iff a < -1$ или $a > 2$;
2. $f(1) = 3 - a > 0 \iff a < 3$;
3. $x_0 = a > 1$.

Пересечение: $2 < a < 3$. **Ответ:** $a \in (2;\,3)$.
:::

## Задача 6
> При каких $a$ уравнение $x^4 - 2ax^2 + a + 2 = 0$ имеет ровно два различных решения?

:::solution
$t = x^2 \ge 0$: $\;t^2 - 2at + a + 2 = 0$. Два $x$ получаются из **одного положительного** $t$. Варианты:

- **Корни $t$ разных знаков:** $t_1 t_2 = a + 2 < 0 \iff a < -2$ → один положительный $t$ → два $x$. ✓
- **Двойной положительный корень:** $\tfrac D4 = a^2 - a - 2 = 0 \iff a = 2$ или $a = -1$; корень $t = a$: при $a = 2$ — $t = 2 > 0$ → $x = \pm\sqrt2$ ✓; при $a = -1$ — $t = -1$ → решений нет.
- **Корень $t = 0$** ($a = -2$): $t^2 + 4t = 0$, $t \in \{0,\,-4\}$ → только $x = 0$ — одно решение. ✗
- Два различных положительных $t$ дают **четыре** $x$. ✗

**Ответ:** $a < -2$ или $a = 2$.
:::

## Задача 7
> Сколько решений имеет $\sin x = a$ на $[0;\,2\pi]$?

:::solution
| $a$ | решений |
|---|---|
| $\lvert a \rvert > 1$ | 0 |
| $a = 1$ | 1 ($\tfrac\pi2$) |
| $a = -1$ | 1 ($\tfrac{3\pi}2$) |
| $0 < \lvert a \rvert < 1$ | 2 |
| $a = 0$ | **3** ($0,\ \pi,\ 2\pi$ — отрезок замкнут!) |
:::

## Задача 8
> При каких $a$ уравнение $2\cos^2 x - 3\cos x + a = 0$ имеет ровно четыре решения на $[0;\,2\pi)$?

:::solution
$t = \cos x \in [-1;\,1]$. Четыре решения — только если **оба** корня $t$ различны и лежат в $(-1;\,1)$ (каждый даёт два $x$; $t = \pm1$ дают по одному).

Выразим параметр: $a = 3t - 2t^2 = h(t)$, $t \in (-1;\,1)$. Парабола ветвями вниз, вершина $t = \tfrac34$, $h\left(\tfrac34\right) = \tfrac98$; $h(-1) = -5$, $h(1) = 1$.

Прямая $y = a$ пересекает график на $(-1;\,1)$ дважды при $1 < a < \tfrac98$. При $a = 1$ второй корень $t = 1$ даёт только $x = 0$ — итого 3 решения.

**Ответ:** $a \in \left(1;\,\tfrac98\right)$.
:::

## Задача 9
> При каких $a$ уравнение $\sin x + \cos x = a$ имеет ровно одно решение на $[0;\,2\pi)$?

:::solution
$\sin x + \cos x = \sqrt2\sin\left(x + \tfrac\pi4\right)$. Когда $x$ пробегает $[0;\,2\pi)$, аргумент пробегает ровно один период. На полном периоде уравнение $\sqrt2\sin u = a$ имеет одно решение только в «вершинах»: $a = \pm\sqrt2$. При $|a| < \sqrt2$ — два решения.

**Ответ:** $a = \pm\sqrt2$.
:::

## Задача 10
> При каких $a$ уравнение $|\sin x| = a$ имеет ровно четыре решения на $[-\pi;\,\pi]$?

:::solution
$|\sin x|$ на $[-\pi;\,\pi]$ — две «горки» высотой 1 (над $[-\pi;\,0]$ и $[0;\,\pi]$). При $0 < a < 1$ каждая горка даёт два решения — итого 4. При $a = 1$ — два, при $a = 0$ — три ($-\pi,\ 0,\ \pi$).

**Ответ:** $0 < a < 1$.
:::

## Задача 11
> При каких $a$ уравнение $\sin 2x = a\sin x$ имеет ровно четыре решения на $[0;\,2\pi)$?

:::solution
$2\sin x\cos x - a\sin x = 0 \iff \sin x\,(2\cos x - a) = 0$.
- $\sin x = 0$: $x = 0,\ \pi$ — два решения всегда.
- $\cos x = \dfrac a2$: нужны ещё **два новых** решения. Если $\left|\dfrac a2\right| < 1$, их два, и они не совпадают с $0$ и $\pi$ (там $\cos x = \pm1$). Если $\dfrac a2 = \pm1$, получаем $x = 0$ или $x = \pi$ — уже посчитаны.

**Ответ:** $-2 < a < 2$.
:::

## Задача 12
> Сколько решений имеет $\dfrac{\sin x - a}{\cos x} = 0$ на $[0;\,2\pi)$?

:::solution
$\sin x = a$, $\cos x \ne 0$ (то есть $x \ne \tfrac\pi2,\ \tfrac{3\pi}2$).
- $|a| < 1$: два решения (при $a = 0$ это $0$ и $\pi$), ни одно не выколото.
- $a = \pm1$: единственное решение $\tfrac\pi2$ или $\tfrac{3\pi}2$ — выколото → 0.
- $|a| > 1$: 0.

**Ответ:** два решения при $-1 < a < 1$, иначе решений нет.
:::

## Задача 13
> При каких $a$ уравнение $|\sin x| + |\cos x| = a$ имеет ровно восемь решений на $[0;\,2\pi)$?

:::solution
Функция $f(x) = |\sin x| + |\cos x|$ имеет период $\tfrac\pi2$. На $\left[0;\,\tfrac\pi2\right]$ это $\sqrt2\sin\left(x + \tfrac\pi4\right)$: растёт от 1 до $\sqrt2$ (при $x = \tfrac\pi4$) и убывает обратно до 1. На $[0;\,2\pi)$ — четыре таких «горки».
- $1 < a < \sqrt2$: по два решения на каждой горке → **8**;
- $a = 1$ или $a = \sqrt2$ — по 4 решения.

**Ответ:** $1 < a < \sqrt2$.
:::

## Задача 14
> При каких $a$ уравнение $\cos 2x = a\cos x$ имеет ровно три решения на $[0;\,2\pi)$?

:::solution
$2\cos^2x - 1 = a\cos x$, $t = \cos x$: $\;2t^2 - at - 1 = 0$. Произведение корней $-\tfrac12 < 0$ — корни **всегда** разных знаков, $t_1 < 0 < t_2$.

Три решения = $1 + 2$: один корень равен $\pm1$ (даёт одно $x$), второй внутри $(-1;\,1)$ (даёт два).
- $t = 1$: $2 - a - 1 = 0 \Rightarrow a = 1$, второй корень $-\tfrac12$ ✓;
- $t = -1$: $2 + a - 1 = 0 \Rightarrow a = -1$, второй корень $\tfrac12$ ✓.

**Ответ:** $a = \pm1$.
:::

## Задача 15
> При каких $a$ неравенство $a + \sin 2x \ge 2\sin x\cos x + \sin x + \cos x$ верно при всех $x$?

:::solution
$\sin 2x = 2\sin x\cos x$ сокращается: $a \ge \sin x + \cos x$ для всех $x$, то есть $a \ge \max(\sin x + \cos x) = \sqrt2$.

**Ответ:** $a \ge \sqrt2$.
:::

## Задача 16
> При каких $a$ уравнение $\sin^2x - 2a\sin x + a = 0$ имеет ровно четыре решения на $[0;\,2\pi)$?

:::solution
$t = \sin x$. Четыре решения — оба корня $g(t) = t^2 - 2at + a$ различны и лежат в $(-1;\,1)$ (тогда каждый даёт два $x$; заметьте, $t = 0$ тоже даёт два: $0$ и $\pi$).

1. $\tfrac D4 = a^2 - a > 0 \iff a < 0$ или $a > 1$;
2. $g(-1) = 1 + 3a > 0 \iff a > -\tfrac13$;
3. $g(1) = 1 - a > 0 \iff a < 1$;
4. вершина $t_0 = a \in (-1;\,1)$.

Пересечение: $-\tfrac13 < a < 0$.

*Граница:* при $a = -\tfrac13$ корни $t = \tfrac13$ и $t = -1$ → $2 + 1 = 3$ решения.

**Ответ:** $a \in \left(-\tfrac13;\,0\right)$.
:::

## Задача 17
> При каких $a$ уравнение $|\sin x - a| = \tfrac12$ имеет ровно три решения на $[0;\,2\pi)$?

:::solution
$\sin x = a + \tfrac12$ или $\sin x = a - \tfrac12$. Значения отличаются на 1, поэтому решения не пересекаются. Три = $1 + 2$: одно из значений равно $\pm1$, другое внутри $(-1;\,1)$.
- $a + \tfrac12 = 1 \Rightarrow a = \tfrac12$: второе значение $0$ → 2 решения. Итого 3 ✓.
- $a - \tfrac12 = -1 \Rightarrow a = -\tfrac12$: второе значение $0$ → итого 3 ✓.
- $a + \tfrac12 = -1$ или $a - \tfrac12 = 1$: второе значение $\mp2$ — решений нет, итого 1.

**Ответ:** $a = \pm\tfrac12$.
:::

## Задача 18
> При каких $a$ уравнения $\sin x(\cos x - a) = 0$ и $\sin x = 0$ имеют одинаковые множества решений?

:::solution
Первое уравнение: $\sin x = 0$ **или** $\cos x = a$. Нужно, чтобы $\cos x = a$ не давало новых решений: либо решений нет ($|a| > 1$), либо все они уже удовлетворяют $\sin x = 0$. Это так при $a = \pm1$ ($x = 2k\pi$ или $x = \pi + 2k\pi$). При $|a| < 1$ появляются $x$ с $\sin x \ne 0$.

**Ответ:** $|a| \ge 1$.
:::

## Задача 19 (домашнее задание, IGCSE)
> При каких $k$ уравнение $kx^2 + k = 8x - 2xk$ имеет два различных действительных корня?

:::solution
Переносим всё влево: $kx^2 + (2k - 8)x + k = 0$.

**$k = 0$:** $-8x = 0$ — один корень. ✗

**$k \ne 0$:** $D = (2k - 8)^2 - 4k^2 = 4k^2 - 32k + 64 - 4k^2 = 64 - 32k > 0 \iff k < 2$.

**Answer:** $k < 2,\ k \ne 0$.
:::

:::warn За что снимают баллы в IGCSE
Ответ «$k < 2$» без «$k \ne 0$» — потеря балла: при $k = 0$ уравнение не квадратное.
:::

## Задача 20 (домашнее задание, IGCSE)
> При каких $k$ парабола $y = 2x^2 + kx + 2k - 6$ лежит строго выше оси $Ox$?

:::solution
Старший коэффициент $2 > 0$, нужно $D < 0$:
$$D = k^2 - 8(2k - 6) = k^2 - 16k + 48 = (k - 4)(k - 12) < 0 \iff 4 < k < 12.$$
**Answer:** $4 < k < 12$.
:::
