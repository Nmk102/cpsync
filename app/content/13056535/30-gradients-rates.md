Юнит *Gradients of Curves & Rates of Change*. Это вход в математический анализ (*calculus*): как измерить **крутизну кривой** в точке и **скорость изменения** величины.

## 1. Градиент прямой

$$m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}.$$
Градиент (*gradient, slope*) — на сколько изменится $y$, если $x$ увеличить на 1. У прямой он **одинаков везде**. Положительный — прямая идёт вверх, отрицательный — вниз.

## 2. Средняя и мгновенная скорость изменения

У кривой крутизна разная в разных местах.

- **Средняя скорость изменения** (*average rate of change*) на $[a;\,b]$ — градиент **хорды** (*chord, secant*) через точки $(a;\,f(a))$ и $(b;\,f(b))$:
$$\frac{f(b) - f(a)}{b - a}.$$
- **Мгновенная скорость изменения** (*instantaneous rate of change*) в точке $x$ — градиент **касательной** (*tangent*) в этой точке.

Как найти градиент касательной? Сближать вторую точку хорды с первой: $h \to 0$.

$$\frac{(1 + h)^2 - 1^2}{h} = \frac{2h + h^2}{h} = 2 + h \;\xrightarrow{h \to 0}\; 2.$$
Градиент кривой $y = x^2$ в точке $x = 1$ равен **2**.

## 3. Производная (*derivative*)

:::def Определение
$$f'(x) = \frac{dy}{dx} = \lim_{h \to 0}\frac{f(x + h) - f(x)}{h}$$
— градиент касательной к графику в точке $x$, или мгновенная скорость изменения $f$.
:::

**Из определения для $f(x) = x^2$:**
$$\frac{(x + h)^2 - x^2}{h} = \frac{2xh + h^2}{h} = 2x + h \to 2x \;\Rightarrow\; (x^2)' = 2x.$$

:::formula Правила (*differentiation rules*)
$$(x^n)' = n x^{n-1}, \qquad (c)' = 0, \qquad (c \cdot f)' = c \cdot f', \qquad (f \pm g)' = f' \pm g'$$
:::

| $f(x)$ | $f'(x)$ |
|---|---|
| $5$ | $0$ |
| $3x$ | $3$ |
| $x^2$ | $2x$ |
| $x^3$ | $3x^2$ |
| $4x^3 - 2x^2 + 7x - 1$ | $12x^2 - 4x + 7$ |
| $\dfrac1x = x^{-1}$ | $-\dfrac1{x^2}$ |
| $\sqrt x = x^{1/2}$ | $\dfrac{1}{2\sqrt x}$ |

## 4. Касательная в точке

Уравнение касательной к $y = f(x)$ в точке $x_0$:
$$y = f(x_0) + f'(x_0)(x - x_0).$$

:::example Касательная к $y = x^3 - 2x$ в точке $x_0 = 1$
$f(1) = -1$, $f'(x) = 3x^2 - 2$, $f'(1) = 1$. Касательная: $y = -1 + 1\cdot(x - 1) = x - 2$.
:::

## 5. Скорость изменения в реальной жизни

| Величина | Её производная |
|---|---|
| координата $s(t)$ | скорость $v(t) = s'(t)$ |
| скорость $v(t)$ | ускорение $a(t) = v'(t)$ |
| объём воды $V(t)$ в баке | скорость наполнения |
| расходы $C(x)$ на выпуск $x$ штук | предельные издержки |

:::example Камень брошен вверх: $h(t) = 20t - 5t^2$ (м). Когда он на максимальной высоте?
$v(t) = h'(t) = 20 - 10t$. В верхней точке скорость равна нулю: $t = 2$ с, $h(2) = 20$ м.
:::

## 6. Знак производной и экстремумы

- $f'(x) > 0$ — функция **возрастает**, $f'(x) < 0$ — **убывает**.
- $f'(x) = 0$ — **стационарная точка**: максимум, минимум или точка перегиба. Проверьте знак $f'$ слева и справа.

## 7. Проверь себя

:::task 1. Средняя скорость изменения $f(x) = x^2 + 1$ на $[1;\,3]$?
:::answer
$\dfrac{f(3) - f(1)}{3 - 1} = \dfrac{10 - 2}{2} = 4$.
:::
:::

:::task 2. Найдите $f'(x)$ для $f(x) = 2x^4 - 3x^2 + x - 7$.
:::answer
$f'(x) = 8x^3 - 6x + 1$.
:::
:::

:::task 3. В какой точке касательная к $y = x^2 - 6x + 5$ горизонтальна?
:::answer
$y' = 2x - 6 = 0 \Rightarrow x = 3$, $y = -4$. Точка $(3;\,-4)$ — вершина параболы.
:::
:::

## 8. Практикум с подробными решениями

:::warn Типичные ошибки
1. $(x^3)' = 3x^3$ — **неверно**: степень уменьшается на 1, $(x^3)' = 3x^2$.
2. $\left(\frac{1}{x^2}\right)' = \frac{1}{2x}$ — неверно. Перепишите $\frac{1}{x^2} = x^{-2}$, тогда $(x^{-2})' = -2x^{-3} = -\frac{2}{x^3}$.
3. Подставили $x_0$ в $f$ вместо $f'$, когда искали градиент касательной.
4. Нашли стационарные точки, но не проверили, максимум это или минимум.
:::

:::solution 1. Из определения (*first principles*): $f(x) = 3x^2 - x$
$$\frac{f(x + h) - f(x)}{h} = \frac{3(x + h)^2 - (x + h) - 3x^2 + x}{h} = \frac{6xh + 3h^2 - h}{h} = 6x + 3h - 1 \xrightarrow{h \to 0} 6x - 1.$$
:::

:::solution 2. Из определения: $f(x) = x^3$ и $f(x) = \frac1x$
$(x + h)^3 - x^3 = 3x^2h + 3xh^2 + h^3$ ⇒ $\frac{\ldots}{h} = 3x^2 + 3xh + h^2 \to 3x^2$.
$\frac{1}{x + h} - \frac1x = \frac{-h}{x(x + h)}$ ⇒ $\frac{\ldots}{h} = -\frac{1}{x(x + h)} \to -\frac{1}{x^2}$.
:::

:::solution 3. Касательная и нормаль к $y = x^2 - 4x + 1$ в точке $x = 3$
$y(3) = -2$, $y' = 2x - 4$, $y'(3) = 2$.
**Касательная:** $y = -2 + 2(x - 3)$, то есть $y = 2x - 8$.
**Нормаль** (*normal*) перпендикулярна касательной: градиент $-\frac{1}{2}$ (произведение градиентов перпендикулярных прямых $= -1$): $y = -2 - \frac12(x - 3)$, то есть $y = -\frac12x - \frac12$.
:::

:::solution 4. В каких точках у кривой $y = x^3 - 3x^2$ градиент равен 9?
$3x^2 - 6x = 9$ ⇔ $x^2 - 2x - 3 = 0$ ⇔ $x = 3$ или $x = -1$. Точки $(3; 0)$ и $(-1; -4)$.
:::

:::solution 5. Стационарные точки $y = x^3 - 6x^2 + 9x + 1$ и их тип
$y' = 3x^2 - 12x + 9 = 3(x - 1)(x - 3)$ ⇒ $x = 1$, $x = 3$.

| $x$ | $x < 1$ | 1 | $1 < x < 3$ | 3 | $x > 3$ |
|---|---|---|---|---|---|
| знак $y'$ | + | 0 | − | 0 | + |
| $y$ | растёт | **max** $y = 5$ | убывает | **min** $y = 1$ | растёт |

Проверка второй производной: $y'' = 6x - 12$; $y''(1) = -6 < 0$ — максимум, $y''(3) = 6 > 0$ — минимум ✓.
:::

:::solution 6. Оптимизация: прямоугольник с периметром 40 и наибольшей площадью
Стороны $x$ и $20 - x$, площадь $S = x(20 - x) = 20x - x^2$. $S' = 20 - 2x = 0$ ⇒ $x = 10$. $S'' = -2 < 0$ — максимум. Квадрат $10 \times 10$, $S = 100$.
:::

:::solution 7. Коробка без крышки из листа 12×12: вырезаем по углам квадраты $x \times x$. Наибольший объём?
$V = x(12 - 2x)^2$, $0 < x < 6$. $V' = (12 - 2x)^2 - 4x(12 - 2x) = (12 - 2x)(12 - 6x)$. Корни $x = 6$ (не подходит — объём 0) и $x = 2$.
$V(2) = 2\cdot8^2 = 128$. Проверка знака: при $x = 1$ $V' > 0$, при $x = 3$ $V' < 0$ — максимум ✓.
:::

:::solution 8. Движение: $s(t) = t^3 - 6t^2 + 9t$ (м). Когда тело стоит? Ускорение в этот момент?
$v = s' = 3t^2 - 12t + 9 = 3(t - 1)(t - 3)$ — стоит при $t = 1$ и $t = 3$ с.
$a = v' = 6t - 12$: $a(1) = -6$ м/с², $a(3) = 6$ м/с².
:::

:::solution 9. Средняя и мгновенная скорость: $f(x) = \sqrt x$ на $[1; 4]$
Средняя: $\frac{2 - 1}{4 - 1} = \frac13$. В какой точке мгновенная скорость такая же? $f'(x) = \frac{1}{2\sqrt x} = \frac13$ ⇒ $x = \frac94$ (это внутри отрезка — так всегда бывает для гладких функций, теорема Лагранжа).
:::
