## 1. Числа и множества (*Forms of Numbers & Sets*)

- $\mathbb N \subset \mathbb Z \subset \mathbb Q \subset \mathbb R$; иррациональные — $\sqrt2$, $\pi$, $\sqrt[3]{5}$.
- Периодическая дробь → обыкновенная: $x = 0{,}\overline{36}$, $100x - x = 36 \Rightarrow x = \frac{36}{99} = \frac4{11}$.
- Множества: $A \cup B$ (объединение), $A \cap B$ (пересечение), $A'$ (дополнение), $n(A \cup B) = n(A) + n(B) - n(A \cap B)$.

:::task Иррационально ли $\sqrt2 + \sqrt8$?
:::answer
$\sqrt8 = 2\sqrt2$, сумма $3\sqrt2$ — иррационально (рациональное, умноженное на иррациональное, иррационально).
:::
:::

## 2. Корни, степени, границы точности (*Surds, exponents, bounds*)

$$a^m a^n = a^{m+n},\quad (a^m)^n = a^{mn},\quad a^{-n} = \frac1{a^n},\quad a^{\frac mn} = \sqrt[n]{a^m},\quad \sqrt{ab} = \sqrt a\sqrt b$$

- Избавление от иррациональности: $\dfrac{6}{3 - \sqrt3} = \dfrac{6(3 + \sqrt3)}{9 - 3} = 3 + \sqrt3$.
- **Границы:** 12 см с точностью до 1 см → $11{,}5 \le L < 12{,}5$. Для частного: **максимум** = верхняя граница числителя / **нижняя** граница знаменателя.

:::task 1) Упростите $\sqrt{50} - \sqrt{18} + \sqrt8$. 2) $8^{2/3}\cdot 27^{-1/3}$. 3) Сторона квадрата 12 см (до 1 см). Границы площади.
:::answer
1) $5\sqrt2 - 3\sqrt2 + 2\sqrt2 = 4\sqrt2$. 2) $4\cdot\frac13 = \frac43$. 3) $11{,}5^2 = 132{,}25 \le S < 12{,}5^2 = 156{,}25$ см².
:::
:::

## 3. Тригонометрия

Подробно — [конспект «Тригонометрия — всё в одном месте»](#/s/13056535/n/50-trigonometry): формулы, уравнения, графики, обратные функции, треугольники, пеленги, Чева и Менелай.

:::task 1) Решите $2\cos^2x - \cos x - 1 = 0$ на $[0;\,2\pi)$. 2) В треугольнике $a = 7$, $b = 5$, $C = 60^\circ$: найдите $c$ и площадь.
:::answer
1) $t = \cos x$: $2t^2 - t - 1 = 0 \Rightarrow t = 1$ или $t = -\frac12$; $x = 0,\ \frac{2\pi}3,\ \frac{4\pi}3$.

2) $c^2 = 49 + 25 - 2\cdot7\cdot5\cdot\frac12 = 39 \Rightarrow c = \sqrt{39}$; $S = \frac12\cdot7\cdot5\cdot\frac{\sqrt3}2 = \frac{35\sqrt3}4$.
:::
:::

## 5. Прямые и координаты (*Linear Decisions & Coordinates*)

$$m = \frac{y_2 - y_1}{x_2 - x_1},\quad y - y_1 = m(x - x_1),\quad m_1 m_2 = -1\ (\perp),\quad d = \sqrt{(\Delta x)^2 + (\Delta y)^2},\quad M = \left(\tfrac{x_1+x_2}2;\ \tfrac{y_1+y_2}2\right)$$

:::task Прямая через $P(1;\,2)$ и $Q(4;\,8)$: уравнение, длина $PQ$, середина, уравнение перпендикуляра через середину.
:::answer
$m = 2$, $y = 2x$. $PQ = \sqrt{9 + 36} = 3\sqrt5$. $M(2{,}5;\ 5)$. Перпендикуляр: $m = -\frac12$, $y - 5 = -\frac12(x - 2{,}5)$, то есть $y = -\frac12x + 6{,}25$.
:::
:::

| призма / цилиндр | $S_{осн}\cdot h$ / $\pi r^2h$ | цилиндр: $2\pi r^2 + 2\pi rh$ |
| пирамида / конус | $\frac13 S_{осн}h$ / $\frac13\pi r^2h$ | конус: $\pi r^2 + \pi rl$ |
| шар | $\frac43\pi r^3$ | $4\pi r^2$ |

:::answer
$l = \sqrt{9 + 16} = 5$. $V = \frac13\pi\cdot9\cdot4 = 12\pi$, боковая поверхность $\pi rl = 15\pi$.

## 8. Квадратные уравнения и параболы

- Выделение полного квадрата: $x^2 + 6x + 5 = (x + 3)^2 - 4$ → вершина $(-3;\,-4)$.
- Квадратное неравенство: найти корни, нарисовать параболу, взять нужные промежутки. $x^2 - 5x + 6 \le 0 \iff x \in [2;\,3]$.
- Пересечение прямой и параболы: приравнять, получится квадратное уравнение; дискриминант покажет число общих точек (касание — $D = 0$).

:::task Найдите точки пересечения $y = x^2$ и $y = x + 2$. При каком $c$ прямая $y = x + c$ касается параболы $y = x^2$?
:::answer
$x^2 - x - 2 = 0 \Rightarrow x = 2,\ -1$: точки $(2;\,4)$, $(-1;\,1)$. Касание: $x^2 - x - c = 0$, $D = 1 + 4c = 0 \Rightarrow c = -\frac14$.
:::
:::
