Листок *TLF10 — Problems with Parameters* (Parameters practice). Задачи заметно сложнее первого листка — это олимпиадные и экзаменационные приёмы. Каждый ответ проверен численно.

:::key Приёмы этого листка
- **Пучок прямых** $y = ax$ или $y = a(x + 1) - 5$: все прямые проходят через одну точку, параметр — наклон. Ищем **касание** и «граничные» прямые.
- **Геометрический смысл**: сумма расстояний до двух точек равна расстоянию между ними → точка на отрезке.
- **Чётность**: если $f(-x) = f(x)$ и решение единственное, то это $x = 0$.
- **Монотонная функция**: если $f$ строго возрастает, то $f(u) = f(v) \iff u = v$.
:::

## Задача 1
> При каких $a$ уравнение $|x^2 - 5x + 6| = ax$ имеет ровно три решения?

:::hint
Нарисуйте $y = |x^2 - 5x + 6|$ («горка» высотой $\tfrac14$ над $[2;\,3]$) и прямую $y = ax$ через начало координат. Три точки пересечения — когда прямая **касается** горки.
:::

:::solution
Левая часть $\ge 0$, поэтому при $a < 0$ нужны $x \le 0$, при $a > 0$ — $x \ge 0$.

**$a = 0$:** $x = 2,\ 3$ — два решения.

**$a < 0$:** при $x \le 0$ модуль раскрывается со знаком «+», $x^2 - (5 + a)x + 6 = 0$. Произведение корней 6, поэтому оба корня отрицательны, только если $5 + a < 0$ и $D \ge 0$, то есть $a \le -5 - 2\sqrt6$: одно или два решения, но не три.

**$a > 0$, вне $(2;\,3)$:** $x^2 - (5 + a)x + 6 = 0$. Обозначим левую часть $p(x)$: $p(2) = -2a < 0$ и $p(3) = -3a < 0$, значит, 2 и 3 лежат **между** корнями: $x_1 < 2$, $x_2 > 3$. Это всегда **два** решения.

**$a > 0$, внутри $(2;\,3)$:** $-(x^2 - 5x + 6) = ax \iff x^2 - (5 - a)x + 6 = 0$.
- $D = (5 - a)^2 - 24 = 0 \iff a = 5 - 2\sqrt6$ (второй корень $5 + 2\sqrt6$ даёт отрицательное $x$): одна точка касания $x = \sqrt6 \in (2;\,3)$ → всего **3** решения ✓;
- $0 < a < 5 - 2\sqrt6$: два корня внутри → всего 4;
- $a > 5 - 2\sqrt6$: внутри корней нет → всего 2.

**Ответ:** $a = 5 - 2\sqrt6$.
:::

## Задача 2
> При каких $a$ уравнение $\dfrac{9x^2 - a^2}{x^2 + 8x + 16 - a^2} = 0$ имеет ровно два решения?

:::solution
Числитель: $x = \pm\dfrac a3$. Знаменатель: $(x + 4)^2 - a^2 \ne 0 \iff x \ne -4 \pm a$.

**$a = 0$:** только $x = 0$ — одно решение.

**$a \ne 0$:** два кандидата $\pm\tfrac a3$. Кандидат выколот, если совпадает с $-4 \pm a$:
- $\tfrac a3 = -4 + a \Rightarrow a = 6$; $\quad \tfrac a3 = -4 - a \Rightarrow a = -3$;
- $-\tfrac a3 = -4 + a \Rightarrow a = 3$; $\quad -\tfrac a3 = -4 - a \Rightarrow a = -6$.

При $a \in \{\pm3,\ \pm6\}$ остаётся одно решение (два сразу выколоты быть не могут).

**Ответ:** $a \ne 0,\ \pm3,\ \pm6$.
:::

## Задача 3
> При каких $a$ неравенство $x^2 + |x + a - 3| + 5 \le 5x + a$ имеет хотя бы одно решение на $[1;\,2]$?

:::hint
Сделайте замену $u = x + a - 3$ (то, что под модулем) и выразите $a = u - x + 3$. Получится неравенство, где модуль стоит в виде $|u| - u$.
:::

:::solution
Перепишем: $x^2 - 5x + 5 - a + |x + a - 3| \le 0$. Пусть $u = x + a - 3$, тогда $a = u - x + 3$:
$$x^2 - 4x + 2 + |u| - u \le 0.$$
- Если $u \ge 0$: $|u| - u = 0$, условие $x^2 - 4x + 2 \le 0 \iff x \in [2 - \sqrt2;\,2 + \sqrt2]$.
- Если $u < 0$: $|u| - u = -2u$, условие $2u \ge x^2 - 4x + 2$, то есть $a \ge \dfrac{x^2 - 6x + 8}{2}$ (и $a < 3 - x$).

Объединяя оба случая: неравенство выполнено $\iff x \in [2 - \sqrt2;\,2 + \sqrt2]$ и
$$a \ge h(x) = \frac{(x - 2)(x - 4)}{2}.$$
Отрезок $[1;\,2]$ целиком лежит в $[2 - \sqrt2;\,2 + \sqrt2]$ (так как $2 - \sqrt2 \approx 0{,}59$). Нужно $a \ge h(x)$ хотя бы для одного $x \in [1;\,2]$, то есть $a \ge \min_{[1;2]} h$. Функция $h$ убывает на $[1;\,3]$, поэтому минимум — $h(2) = 0$.

**Ответ:** $a \ge 0$.
:::

## Задача 4
> При каких $a$ уравнение $\sqrt{x^2 + 6x + 8} = \sqrt{x + a}$ имеет ровно одно **отрицательное** решение?

:::solution
Равенство корней $\iff$ подкоренные выражения равны и неотрицательны:
$$x^2 + 6x + 8 = x + a,\qquad x^2 + 6x + 8 \ge 0 \iff x \le -4\ \text{или}\ x \ge -2.$$
Выразим $a = x^2 + 5x + 8 = g(x)$ и посмотрим на отрицательные $x$ из $(-\infty;\,-4] \cup [-2;\,0)$:
- на $(-\infty;\,-4]$ функция $g$ убывает от $+\infty$ до $g(-4) = 4$ → одно решение при $a \ge 4$;
- на $[-2;\,0)$ функция $g$ возрастает от $g(-2) = 2$ до $8$ (не включая) → одно решение при $2 \le a < 8$.

Отрицательных решений: $a < 2$ — 0; $2 \le a < 4$ — 1; $4 \le a < 8$ — 2; $a \ge 8$ — 1.

**Ответ:** $a \in [2;\,4) \cup [8;\,+\infty)$.
:::

## Задача 5
> При каких $a$ система $(x - 3)^2 + (y + 1)^2 = 4,\ \ y = ax + a - 5$ имеет ровно два решения?

:::solution
Окружность: центр $C(3;\,-1)$, радиус 2. Прямая $y = a(x + 1) - 5$ проходит через точку $P(-1;\,-5)$ при любом $a$ — это **пучок прямых** с наклоном $a$.

Два решения $\iff$ расстояние от $C$ до прямой $ax - y + a - 5 = 0$ меньше 2:
$$\frac{|3a + 1 + a - 5|}{\sqrt{a^2 + 1}} < 2 \iff 2|a - 1| < \sqrt{a^2 + 1} \iff 3a^2 - 8a + 3 < 0.$$
**Ответ:** $\dfrac{4 - \sqrt7}{3} < a < \dfrac{4 + \sqrt7}{3}$.
:::

## Задача 6
> При каких $a$ система $y^2 - (2a + 1)y + a^2 + a - 2 = 0$, $\ \sqrt{(x - a)^2 + y^2} + \sqrt{(x - a)^2 + (y - 3)^2} = 3$ имеет ровно одно решение?

:::hint
Второе уравнение: сумма расстояний от точки $(x;\,y)$ до $A(a;\,0)$ и $B(a;\,3)$ равна $|AB| = 3$. Где лежит такая точка?
:::

:::solution
**Второе уравнение.** $|MA| + |MB| = |AB|$ ровно тогда, когда $M$ лежит на **отрезке** $AB$ (неравенство треугольника обращается в равенство). Значит, $x = a$, $0 \le y \le 3$.

**Первое уравнение** раскладывается: $(y - (a + 2))(y - (a - 1)) = 0$, то есть $y = a + 2$ или $y = a - 1$.

Решения системы — точки $(a;\,y)$ с $y \in \{a - 1,\ a + 2\} \cap [0;\,3]$:
- $a - 1 \in [0;\,3] \iff 1 \le a \le 4$;
- $a + 2 \in [0;\,3] \iff -2 \le a \le 1$.

Оба сразу — только $a = 1$ (два решения). Ровно одно — когда выполнено ровно одно условие.

**Ответ:** $a \in [-2;\,1) \cup (1;\,4]$.
:::

## Задача 7
> При каких $a$ уравнение $|a - 2|x^4 - 2ax^2 + |a - 12| = 0$ имеет хотя бы два различных решения?

:::solution
$t = x^2 \ge 0$. Два и больше решений по $x$ даёт любой **положительный** корень $t$.

**$a = 2$:** $-4x^2 + 10 = 0$ → $x = \pm\sqrt{2{,}5}$ ✓.

**$a = 12$:** $10x^4 - 24x^2 = 0$ → $x = 0,\ \pm\sqrt{2{,}4}$ ✓.

**Остальные $a$:** $|a - 2|\,t^2 - 2at + |a - 12| = 0$, где $|a - 2| > 0$, $|a - 12| > 0$. Произведение корней положительно, значит, корни одного знака; положительные — если сумма $\dfrac{2a}{|a - 2|} > 0$, то есть $a > 0$, и $D \ge 0$:
$$a^2 \ge |a - 2|\cdot|a - 12| = |a^2 - 14a + 24|.$$
- $a \in (2;\,12)$: $a^2 \ge -a^2 + 14a - 24 \iff (a - 3)(a - 4) \ge 0 \iff a \le 3$ или $a \ge 4$;
- $a \in (0;\,2) \cup (12;\,+\infty)$: $a^2 \ge a^2 - 14a + 24 \iff a \ge \tfrac{12}7$.

Собираем: $\left[\tfrac{12}7;\,2\right) \cup \{2\} \cup (2;\,3] \cup [4;\,12) \cup \{12\} \cup (12;\,+\infty)$.

**Ответ:** $a \in \left[\tfrac{12}{7};\,3\right] \cup [4;\,+\infty)$.
:::

## Задача 8
> При каких $a$ уравнение $(\tan x + 6)^2 - (a^2 + 2a + 8)(\tan x + 6) + a^2(2a + 8) = 0$ имеет ровно два решения на $\left[0;\,\tfrac{3\pi}2\right]$?

:::hint
Это квадратное уравнение относительно $u = \tan x + 6$. Подберите корни по теореме Виета.
:::

:::solution
По Виету: $u = a^2$ или $u = 2a + 8$, то есть
$$\tan x = a^2 - 6 = c_1 \quad\text{или}\quad \tan x = 2a + 2 = c_2.$$

**Сколько решений у $\tan x = c$ на $\left[0;\,\tfrac{3\pi}2\right]$** (точки $\tfrac\pi2$ и $\tfrac{3\pi}2$ не входят в область определения): $c > 0$ — два (в $(0;\,\tfrac\pi2)$ и $(\pi;\,\tfrac{3\pi}2)$); $c = 0$ — два ($0$ и $\pi$); $c < 0$ — одно (в $(\tfrac\pi2;\,\pi)$). Значит, **каждое** уравнение даёт хотя бы одно решение.

**Если $c_1 = c_2$** ($a^2 - 2a - 8 = 0$, то есть $a = 4$ или $a = -2$): $a = 4$ даёт $c = 10 > 0$ → 2 решения ✓; $a = -2$ даёт $c = -2$ → 1 решение ✗.

**Если $c_1 \ne c_2$:** всего ровно 2 только при $1 + 1$, то есть оба $c$ отрицательны: $a^2 < 6$ и $a < -1$, то есть $-\sqrt6 < a < -1$, кроме $a = -2$.

**Ответ:** $a \in (-\sqrt6;\,-2) \cup (-2;\,-1) \cup \{4\}$.
:::

## Задача 9
> При каких $a$ уравнение $\sqrt{a^2 + x^2} = \cos 2x + a^2 + 2a - 1$ имеет ровно одно решение?

:::solution
**Необходимость.** Обе части — **чётные** функции $x$: если $x_0$ — решение, то $-x_0$ тоже. Единственное решение возможно только при $x_0 = 0$. Подставим $x = 0$:
$$|a| = a^2 + 2a.$$
$a \ge 0$: $a^2 + a = 0 \Rightarrow a = 0$. $\quad a < 0$: $a^2 + 3a = 0 \Rightarrow a = -3$.

**Достаточность** (обязательно проверить!):
- $a = 0$: $|x| = \cos 2x - 1 \le 0$ → только $x = 0$ ✓.
- $a = -3$: $\sqrt{9 + x^2} = \cos 2x + 2$. Левая часть $\ge 3$ (равенство при $x = 0$), правая $\le 3$ (равенство при $\cos 2x = 1$). Равенство возможно только когда обе равны 3 → $x = 0$ ✓.

**Ответ:** $a = 0$ или $a = -3$.
:::

## Задача 10
> При каких $a$ уравнение $27x^6 + (3a - 4x)^3 + 3x^2 + 3a = 4x$ имеет хотя бы одно решение?

:::hint
$27x^6 = (3x^2)^3$. Сгруппируйте: $\big[(3x^2)^3 + 3x^2\big] + \big[(3a - 4x)^3 + (3a - 4x)\big] = 0$.
:::

:::solution
Пусть $f(t) = t^3 + t$. Уравнение — это $f(3x^2) + f(3a - 4x) = 0$.

$f$ нечётная, поэтому $f(3x^2) = -f(3a - 4x) = f(4x - 3a)$. И $f$ **строго возрастает** (сумма возрастающих $t^3$ и $t$), значит, равенство значений означает равенство аргументов:
$$3x^2 = 4x - 3a \iff 3x^2 - 4x + 3a = 0.$$
Решение есть $\iff$ $\dfrac D4 = 4 - 9a \ge 0 \iff a \le \dfrac49$.

**Ответ:** $a \le \dfrac49$.
:::
