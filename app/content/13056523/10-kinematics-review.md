Юнит 1 (*Advanced Kinematics*) закончился, но эти идеи нужны дальше — в динамике вращения и на контрольных. Ниже ключевые формулы и **краткие** решения: главное — идея; полное оформление вы уже делали.

## Ключевые идеи

:::formula Движение по окружности
$$\omega = \frac{\Delta\varphi}{\Delta t},\quad v = \omega R,\quad a_n = \frac{v^2}{R} = \omega^2 R = \omega v,\quad a_\tau = \frac{dv}{dt}$$
:::

:::formula Радиус кривизны траектории
В любой точке траектории $\rho = \dfrac{v^2}{a_n}$, где $a_n$ — составляющая ускорения, **перпендикулярная скорости**.
:::

:::key Качение без проскальзывания
- Точка касания с поверхностью **неподвижна** (мгновенная ось вращения): $v_{центра} = \omega R$.
- Скорость любой точки колеса $= \omega \cdot (\text{расстояние до точки касания})$, направлена перпендикулярно этому отрезку.
- Верхняя точка движется со скоростью $2v_0$.
- Ускорение точки обода $= \vec a_0 + \vec a_\tau + \vec a_n$, где $a_\tau = \varepsilon R = a_0$ (по касательной), $a_n = \omega^2 R$ (к центру).
:::

## Hometask 1. Angular velocity

:::solution 1. Часы показывают 16:00. Через сколько минут стрелки встретятся во второй раз?
Минутная стрелка догоняет часовую с относительной угловой скоростью $\omega_m - \omega_h = 2\pi\left(\frac1{60} - \frac1{720}\right) = \frac{11\cdot 2\pi}{720}$ рад/мин. В 16:00 часовая впереди на $\frac{2\pi}{3}$; до второй встречи нужно отыграть $\frac{2\pi}3 + 2\pi = \frac{8\pi}3$:
$$t = \frac{8\pi}{3(\omega_m - \omega_h)} = \frac{8\cdot 720}{3\cdot 22} \approx 87{,}3\ \text{мин}.$$
:::

:::solution 2. Шарик влетает в отверстие вращающегося цилиндра. При какой $\omega$ он вылетит, не задев стенку?
Шарик пролетает диаметр $2R$ за $t = \frac{2R}{v}$. За это время отверстие должно оказаться в противоположной точке: $\omega t = \pi + 2\pi n$:
$$\omega = \frac{(2n + 1)\pi v}{2R},\quad n = 0, 1, 2, \ldots$$
:::

:::solution 3. Скорость $v = 0{,}5$ м/с поворачивается на $30^\circ$ за 2 с. Найти $a_n$.
Вектор скорости вращается с угловой скоростью $\Omega = \frac{\Delta\varphi}{\Delta t} = \frac{\pi/6}{2}$. Нормальное ускорение $a_n = \Omega v = \frac{\pi v}{6\Delta t} \approx 0{,}13$ м/с².
:::

:::solution 4. С какой скоростью летит спутник, «падая» с ускорением $g$ по окружности $R = 6400$ км?
$\frac{v^2}{R} = g \Rightarrow v = \sqrt{gR} \approx 8$ км/с (первая космическая).
:::

:::solution 5. $v = 10^6$ м/с, $a = 10^4$ м/с² под $30^\circ$ к скорости. Δv за $10^{-2}$ с, поворот скорости, угловая скорость поворота.
$a_\tau = a\cos30^\circ \approx 8{,}7\cdot10^3$ м/с² → $\Delta v \approx 87$ м/с. $a_n = a\sin30^\circ = 5\cdot10^3$ м/с² → $\Omega = \frac{a_n}{v} = 5\cdot10^{-3}$ с⁻¹, угол $\Omega\Delta t = 5\cdot10^{-5}$ рад.
:::

## Hometask 2. Radius of curvature

:::solution 1. Радиус кривизны траектории верхней точки катящегося колеса.
Скорость верхней точки $2v_0$. В системе центра колеса (инерциальной: $v_0$ постоянна) точка движется по окружности со скоростью $v_0$, её ускорение $\frac{v_0^2}{R}$ — вниз, то есть перпендикулярно скорости. $\rho = \frac{(2v_0)^2}{v_0^2/R} = 4R$.
:::

:::solution 2. Радиус кривизны траектории брошенного тела $\rho(t)$.
$a_n = g\cos\theta = g\frac{v_x}{v}$, где $v_x = v_0\cos\alpha$. Тогда $\rho = \frac{v^2}{a_n} = \frac{v^3}{g v_x}$:
$$\rho(t) = \frac{\left((v_0\cos\alpha)^2 + (v_0\sin\alpha - gt)^2\right)^{3/2}}{g v_0\cos\alpha}.$$
:::

:::solution 3. Край стола скруглён радиусом $r$. При какой скорости тело сразу полетит по параболе?
Чтобы тело оторвалось сразу, тяжести должно **не хватать** для удержания на окружности: $\frac{v^2}r \ge g \Rightarrow v_{min} = \sqrt{gr}$.
:::

:::solution 4. Камень перелетает шаровой бак радиуса $R$, касаясь его верха. Минимальная скорость броска?
В верхней точке (высота $2R$) траектория не должна быть «кривее» бака: $\rho = \frac{v_{верх}^2}{g} \ge R \Rightarrow v_{верх}^2 \ge gR$. По закону сохранения энергии $v_0^2 = v_{верх}^2 + 2g\cdot2R \ge 5gR$: $v_{min} = \sqrt{5gR}$.
:::

:::solution 5. Пчела летит по траектории сахара с постоянной скоростью $v_0$. Ускорение в верхней точке?
Радиус кривизны траектории в верхней точке (по сахару): $\rho = \frac{(v_0\cos\alpha)^2}{g}$. Пчела проходит её со скоростью $v_0$, тангенциального ускорения нет: $a = \frac{v_0^2}{\rho} = \frac{g}{\cos^2\alpha}$, вниз.
:::

## Hometask 3. Rolling motion

:::solution 1. Обруч: скорости концов диаметра $AB$ равны $v_A$, $v_B$ и перпендикулярны $AB$. Скорости концов диаметра $CD$?
Скорость центра $v_O = \frac{v_A + v_B}{2}$ (вдоль $CD$), угловая скорость $\omega = \frac{v_B - v_A}{2R}$. Для точки $C$: к $v_O$ добавляется $\omega R = \frac{|v_B - v_A|}{2}$ вдоль $AB$:
$$v_C = v_D = \sqrt{\frac{v_A^2 + v_B^2}{2}},\qquad \tan\varphi = \frac{|v_B - v_A|}{v_A + v_B}\ \text{(угол с } CD).$$
:::

:::solution 2. Катушка между досками (верхняя доска $v_1$ касается внутреннего радиуса $r$, нижняя $v_2$ — внешнего $R$).
Без проскальзывания: $v_0 + \omega r = v_1$ (верх), $v_0 - \omega R = v_2$ (низ). Вычитаем:
$$\omega = \frac{v_1 - v_2}{R + r}, \qquad v_0 = v_1 - \omega r = \frac{v_1 R + v_2 r}{R + r}.$$
(Именно здесь учитель отметил описку: $v_0 = v_1 - \omega r$, а не $\omega R$.)
:::

:::solution 3. Подшипник: внутреннее кольцо $\omega_1, r_1$ (против часовой), внешнее $\omega_2, r_2$ (по часовой). Скорость центров шариков?
Точки касания шарика движутся вместе с кольцами: $\omega_1 r_1$ в одну сторону и $\omega_2 r_2$ — в другую. Центр шарика — середина между точками касания, его скорость — среднее:
$$v = \frac{|\omega_1 r_1 - \omega_2 r_2|}{2}.$$
:::

:::solution 4. Колесо катится с ускорением центра $a_0$. Ускорения точек $A$ (верх) и $B$ (задняя точка горизонтального диаметра), когда $|a_C| = a_0$ ($C$ — точка касания)?
Для любой точки обода: $\vec a = \vec a_0 + \vec a_\tau + \vec a_n$, $|a_\tau| = a_0$, $a_n = \omega^2R$ к центру.
- Точка $C$: $\vec a_0$ и $\vec a_\tau$ гасят друг друга, остаётся $a_n = \omega^2R$ (вверх). Условие: $\omega^2R = a_0$.
- Точка $A$ (верх): вперёд $a_0 + a_0 = 2a_0$, вниз $a_n = a_0$ → $a_A = \sqrt5\,a_0$.
- Точка $B$ (сзади): вперёд $a_0$ (поступательное) $+ a_0$ ($a_n$ к центру), вверх $a_\tau = a_0$ → $a_B = \sqrt5\,a_0$.
:::

:::solution 5. Катушка катится, нить сходит с низа внутреннего цилиндра (радиус $r$) горизонтально со скоростью $u$. Скорость оси $v$, скорость и ускорение верхней точки $A$?
Мгновенная ось — точка касания со столом. Точка схода нити на высоте $R - r$ над ней: $u = \omega(R - r)$, значит
$$v = \omega R = \frac{uR}{R - r}\ \text{(в сторону } \vec u),\qquad v_A = \omega\cdot2R = \frac{2uR}{R - r}.$$
$\omega$ постоянна, поэтому у точки $A$ только центростремительное ускорение к оси: $a_A = \omega^2R = \frac{u^2R}{(R - r)^2}$.
:::
