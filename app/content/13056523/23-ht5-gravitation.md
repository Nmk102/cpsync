Юнит *Gravity and Electrostatics: Fields and Forces at a Distance*. Ключевая идея юнита — **поле**: тело создаёт вокруг себя поле, и другое тело чувствует силу, не касаясь первого.

## Теория

:::def Закон всемирного тяготения (*Newton's law of universal gravitation*)
$$F = G\,\frac{m_1 m_2}{r^2}, \qquad G \approx 6{,}67\cdot 10^{-11}\ \frac{\text{Н}\cdot\text{м}^2}{\text{кг}^2}.$$
Сила направлена вдоль прямой, соединяющей тела, — это всегда притяжение.
:::

:::def Напряжённость гравитационного поля (*gravitational field strength*)
$$g = \frac{F}{m} = G\frac{M}{r^2}\quad \left[\frac{\text{Н}}{\text{кг}} = \frac{\text{м}}{\text{с}^2}\right].$$
На поверхности планеты радиуса $R$: $g_0 = \dfrac{GM}{R^2}$. На высоте $h$: $g(h) = g_0\left(\dfrac{R}{R + h}\right)^2$. Вес тела $W = mg$ — поэтому $g$ разный на разных планетах и на разной высоте.
:::

**Теорема о сферах (*shell theorem*).** Однородный шар (или шар со сферически симметричной плотностью) притягивает внешние тела так, будто вся его масса собрана в центре. Поэтому формулу $F = G\frac{Mm}{r^2}$ можно применять к планетам и шарам, если $r$ — расстояние **до центра**.

**Принцип суперпозиции.** Силы от нескольких тел складываются **как векторы**. Шар с полостью = целый шар **минус** шар на месте полости («отрицательная масса»).

:::formula Круговые орбиты
Сила тяготения создаёт центростремительное ускорение: $\dfrac{GMm}{r^2} = \dfrac{mv^2}{r}$
$$v = \sqrt{\frac{GM}{r}}, \qquad T = 2\pi\sqrt{\frac{r^3}{GM}}\quad(\text{третий закон Кеплера: } T^2 \propto r^3).$$
**Первая космическая скорость** (орбита у самой поверхности): $v_1 = \sqrt{gR} \approx 7{,}9$ км/с для Земли.
:::

:::tip Плотность через период орбиты
$M = \dfrac{4\pi^2 r^3}{GT^2}$ и $\rho = \dfrac{M}{\frac43\pi R^3}$. Если спутник летит у самой поверхности ($r = R$): $\rho = \dfrac{3\pi}{GT^2}$ — плотность планеты определяется **только периодом**.
:::

## Задача 1. Два шара касаются

> Два одинаковых однородных шара касаются и притягиваются с силой $F$. Как изменится сила, если массу каждого увеличить в $n$ раз, а плотность материала оставить прежней?

:::key Идея
Ловушка: кажется, что ответ $n^2$ (масса каждого шара выросла в $n$ раз). Но шары **касаются**, и при росте массы растёт и их радиус — значит, растёт расстояние между центрами.
:::

:::solution Решение по шагам
**Шаг 1. Сила сейчас.** По теореме о сферах шары притягиваются как точки в их центрах. Расстояние между центрами касающихся шаров $2r$:
$$F = G\frac{m^2}{(2r)^2}.$$

**Шаг 2. Как меняется радиус.** $m = \rho\cdot\frac43\pi r^3$, плотность та же, поэтому $m \propto r^3$. Масса выросла в $n$ раз ⇒ радиус вырос в $\sqrt[3]{n} = n^{1/3}$ раз.

**Шаг 3. Новая сила:**
$$F' = G\frac{(nm)^2}{(2r\,n^{1/3})^2} = \frac{n^2}{n^{2/3}}\cdot G\frac{m^2}{(2r)^2} = n^{4/3}F.$$

**Ответ:** сила увеличится в $n^{4/3}$ раз.
:::

:::tip Проверка числами
$n = 8$: радиус вырастет вдвое, масса в 8 раз. Сила: $\frac{8^2}{2^2} = 16 = 8^{4/3}$ ✓.
:::

:::key Идея
Чтобы тело двигалось по окружности, равнодействующая всех сил должна равняться $\frac{mv^2}{R}$ и смотреть к центру. Тяготение даёт столько, сколько хватает только для **обычной** круговой скорости. Остальное должен добавить двигатель.
:::

:::solution Решение по шагам
**Шаг 1. Круговая скорость.** Для обычной круговой орбиты тяготение и есть центростремительная сила:
$$G\frac{Mm}{R^2} = \frac{mv_1^2}{R}\ \Rightarrow\ v_1^2 = \frac{GM}{R}.$$

**Шаг 2. Сколько нужно при скорости $2v_1$:**
$$\frac{m(2v_1)^2}{R} = 4\,\frac{mv_1^2}{R} = 4\,G\frac{Mm}{R^2}.$$

**Шаг 3. Второй закон Ньютона** (проекция на направление к центру): $F_{тяг} + F_{дв} = 4G\frac{Mm}{R^2}$, где $F_{тяг} = G\frac{Mm}{R^2}$:
$$F_{дв} = 3\,G\frac{Mm}{R^2}.$$
Скорость по модулю постоянна, значит, вдоль скорости сил нет: двигатель тянет **строго к центру планеты**.
:::

:::warn Типичная ошибка
Думать, что двигатель должен тянуть «вперёд», раз скорость больше. Вперёд тянуть не нужно: по модулю скорость не меняется. Двигатель нужен, чтобы **поворачивать** быструю скорость, иначе спутник улетит по вытянутой орбите.
:::

Шар с полостью = целый шар + «шарик с отрицательной массой» на месте полости. Силы складываются как векторы — по теореме косинусов.
:::

:::solution Решение
**Сила от целого шара** (к центру $A$):
$$F_1 = G\frac{\frac43\pi R^3\rho\, m}{l^2} = \frac43\pi G\rho m\frac{R^3}{l^2}.$$
**Сила от «полости»** (её вычитаем; по модулю как от шарика радиуса $r$ в точке $C$):
$$F_2 = \frac43\pi G\rho m\frac{r^3}{BC^2}.$$
Результирующая: $\vec F = \vec F_1 - \vec F_2$, где $\vec F_1$ направлена по $BA$, а $\vec F_2$ (до вычитания) — по $BC$. Угол между ними — $\angle ABC = \beta$:
$$F = \sqrt{F_1^2 + F_2^2 - 2F_1F_2\cos\beta}.$$

**а) $\angle ACB = 90^\circ$.** Тогда $BC^2 = l^2 - s^2$, $\cos\beta = \dfrac{BC}{AB} = \dfrac{\sqrt{l^2 - s^2}}{l}$:
$$F_2 = \frac43\pi G\rho m\frac{r^3}{l^2 - s^2}, \qquad F = \sqrt{F_1^2 + F_2^2 - 2F_1F_2\frac{\sqrt{l^2 - s^2}}{l}}.$$

**б) $\angle BAC = 90^\circ$.** Тогда $BC^2 = l^2 + s^2$, $\cos\beta = \dfrac{AB}{BC} = \dfrac{l}{\sqrt{l^2 + s^2}}$:
$$F_2 = \frac43\pi G\rho m\frac{r^3}{l^2 + s^2}, \qquad F = \sqrt{F_1^2 + F_2^2 - 2F_1F_2\frac{l}{\sqrt{l^2 + s^2}}}.$$
:::

## Задача 4. Зонд у астероида Эрос

> Зонд будет летать вокруг Эроса на высоте $n = \frac1{15}$ его радиуса с периодом $T = 4{,}5$ ч. Найти среднюю плотность астероида.

:::solution Решение
Радиус орбиты $r = R(1 + n)$. Из условия круговой орбиты $GM = \dfrac{4\pi^2 r^3}{T^2}$:
$$\rho = \frac{M}{\frac43\pi R^3} = \frac{3}{4\pi R^3}\cdot\frac{4\pi^2R^3(1 + n)^3}{GT^2} = \boxed{\frac{3\pi(1 + n)^3}{GT^2}}.$$
Числа: $T = 4{,}5 \cdot 3600 = 16\,200$ с, $(1 + n)^3 = \left(\tfrac{16}{15}\right)^3 \approx 1{,}214$:
$$\rho = \frac{3\pi \cdot 1{,}214}{6{,}67\cdot10^{-11}\cdot(16\,200)^2} \approx 650\ \text{кг/м}^3.$$
Радиус астероида не понадобился — он сократился.
:::

## Задача 5. Три астероида

> Три астероида сближаются вдоль одной прямой. Отношение расстояний от среднего до крайних всё время равно $n = 2$ (слева $r$, справа $2r$), вплоть до столкновения. Массы $m_1$ (левый), $m_2$ (средний). Найти $m_3$.

:::hint Подсказка
Если отношение расстояний сохраняется, то $x_3 - x_2 = 2(x_2 - x_1)$ **всё время**. Дважды продифференцируйте по времени: такая же связь должна выполняться для **ускорений**.
:::

:::solution Решение
**Связь ускорений:** $a_3 - a_2 = 2(a_2 - a_1)$.

Ускорения (ось вправо; каждое тело притягивается к двум другим):
$$a_1 = G\left(\frac{m_2}{r^2} + \frac{m_3}{(3r)^2}\right), \quad a_2 = G\left(-\frac{m_1}{r^2} + \frac{m_3}{(2r)^2}\right), \quad a_3 = -G\left(\frac{m_1}{(3r)^2} + \frac{m_2}{(2r)^2}\right).$$
Умножим всё на $\dfrac{r^2}{G}$ и подставим в связь:
$$\left(-\frac{m_1}{9} - \frac{m_2}{4}\right) - \left(-m_1 + \frac{m_3}{4}\right) = 2\left(-m_1 + \frac{m_3}{4} - m_2 - \frac{m_3}{9}\right).$$
Слева: $\tfrac89 m_1 - \tfrac14 m_2 - \tfrac14 m_3$. Справа: $-2m_1 - 2m_2 + \tfrac{5}{18}m_3$. Переносим:
$$\frac{26}{9}m_1 + \frac74 m_2 = \frac{19}{36}m_3 \;\Rightarrow\; \boxed{m_3 = \frac{104\,m_1 + 63\,m_2}{19}}.$$
Ответ не зависит от $r$: все слагаемые $\propto 1/r^2$, поэтому условие выполняется на всём пути — так и должно быть.
:::

:::tip Проверка компьютерным моделированием
Я численно промоделировал движение трёх тел с массами $m_1 = m_2 = 1$ и $m_3 = \frac{167}{19} \approx 8{,}79$, а также с другими парами $m_1, m_2$. Тела стартуют из покоя с расстояниями 1 и 2. Отношение расстояний оставалось ровно 2,000 до самого сближения ✓. Если взять $m_3$ на 10 % больше или меньше, отношение сразу начинает «уплывать».
:::
