:::key Идея
Это задача «на догонялки», только по кругу. Минутная стрелка догоняет часовую с **относительной** угловой скоростью $\omega_m - \omega_h$. Встреча — когда минутная «отыграла» начальное отставание плюс целое число полных кругов.
:::

:::solution Решение по шагам
**Шаг 1. Угловые скорости.** Минутная стрелка делает оборот за 60 мин, часовая — за 12 ч = 720 мин:
$$\omega_m = \frac{2\pi}{60}\ \frac{\text{рад}}{\text{мин}}, \qquad \omega_h = \frac{2\pi}{720}\ \frac{\text{рад}}{\text{мин}}.$$

**Шаг 2. Начальное отставание.** В 16:00 минутная стрелка смотрит на 12, часовая — на 4. Между ними $\frac{4}{12}$ оборота, то есть $\frac{2\pi}{3}$. Минутная **отстаёт** (обе крутятся по часовой стрелке, часовая впереди).

**Шаг 3. Относительная скорость.**
$$\omega_m - \omega_h = 2\pi\left(\frac{1}{60} - \frac{1}{720}\right) = 2\pi \cdot \frac{12 - 1}{720} = \frac{11\cdot 2\pi}{720}\ \frac{\text{рад}}{\text{мин}}.$$

**Шаг 4. Встречи.**
- Первая встреча: минутная отыграла $\frac{2\pi}{3}$:
$$t_1 = \frac{2\pi/3}{11\cdot 2\pi/720} = \frac{720}{33} = \frac{240}{11} \approx 21{,}8\ \text{мин}.$$
- Вторая встреча: минутная отыграла ещё один полный круг: $\frac{2\pi}{3} + 2\pi = \frac{8\pi}{3}$.
$$t_2 = \frac{8\pi/3}{11\cdot 2\pi/720} = \frac{8\cdot 720}{3\cdot 22} = \frac{960}{11} \approx 87{,}3\ \text{мин}.$$

**Ответ:** $t = \dfrac{8\pi}{3(\omega_m - \omega_h)} \approx 87{,}3$ мин, то есть примерно в 17:27.
:::

:::tip Проверка другим способом
Стрелки встречаются каждые $\frac{2\pi}{\omega_m - \omega_h} = \frac{720}{11} \approx 65{,}5$ мин (всем известное «каждые 1 ч 5,5 мин»). Первая встреча в $\approx 16{:}21{,}8$, вторая через 65,5 мин: $21{,}8 + 65{,}5 = 87{,}3$ мин ✓.

То же в градусах: минутная стрелка идёт $6^\circ$/мин, часовая — $0{,}5^\circ$/мин. Догоняет со скоростью $5{,}5^\circ$/мин, отставание $120^\circ + 360^\circ = 480^\circ$: $t = \frac{480}{5{,}5} \approx 87{,}3$ мин ✓.
:::

## Задача 2. Шарик и вращающийся цилиндр

> Маленький шарик со скоростью $v$ влетает в маленькое отверстие в стенке полого цилиндра, вращающегося вокруг своей оси. Радиус цилиндра $R$ много больше толщины стенки. Скорость шарика перпендикулярна оси. Какой должна быть угловая скорость ω цилиндра, чтобы шарик вылетел, не задев стенку? Силу тяжести не учитывать.

:::key Идея
Внутри цилиндра на шарик ничего не действует, поэтому он летит **по прямой** вдоль диаметра. Отверстие одно. Чтобы шарик вылетел, отверстие должно оказаться **в противоположной точке** ровно тогда, когда шарик туда долетит.
:::

:::solution Решение по шагам
**Шаг 1. Время пролёта.** Шарик пролетает диаметр $2R$ с постоянной скоростью $v$:
$$t = \frac{2R}{v}.$$

**Шаг 2. На какой угол должен повернуться цилиндр.** Отверстие было в точке влёта, а должно оказаться в диаметрально противоположной точке. Это поворот на $\pi$. Но можно повернуться ещё и на целое число лишних оборотов:
$$\varphi = \pi + 2\pi n = (2n + 1)\pi, \qquad n = 0, 1, 2, \ldots$$

**Шаг 3. Угловая скорость.**
$$\omega = \frac{\varphi}{t} = \frac{(2n + 1)\pi}{2R/v} = \frac{(2n + 1)\pi v}{2R}, \qquad n = 0, 1, 2, \ldots$$
:::

:::tip Проверка и смысл
- Если бы ω была такой, что цилиндр повернулся бы на $2\pi$ (целый оборот), отверстие вернулось бы к точке влёта, а шарик ударился бы в стенку напротив. Поэтому подходят только **нечётные** числа π.
- Размерность: $\frac{v}{R}$ — это $\frac{\text{м/с}}{\text{м}} = \text{с}^{-1}$ ✓.
- Ответ — бесконечная серия значений. Это нормально: в задачах про вращение почти всегда так.
:::

:::warn Типичная ошибка
Писать только $\omega = \frac{\pi v}{2R}$ (забыть про $n$). На контрольной за это снимают баллы.
:::

  <line class="l c5" x1="260.0" y1="200.0" x2="232.9" y2="98.7" style="stroke-width:2.2"/>

  <text class="i" x="108.0" y="188.0">Δφ</text>
  <text class="i" x="320.0" y="52.0">Δφ = 30° = π/6 за Δt = 2 с</text>
  <text class="s" x="320.0" y="82.0">|v₁| = |v₂| = v — меняется только</text>
  <text class="s" x="320.0" y="100.0">направление → ускорение нормальное</text>
  <text class="i" x="320.0" y="134.0">Ω = Δφ/Δt  — скорость поворота</text>
  <text class="i tc5" x="320.0" y="164.0">aₙ = v · Ω</text>
</svg>

:::key Идея
Радиус окружности не дан, и он не нужен. Используем запись $a_n = v\,\Omega$, где Ω — скорость поворота вектора скорости (теория, раздел 2).
:::

:::solution Решение по шагам
**Шаг 1. Переводим угол в радианы:** $30^\circ = \frac{\pi}{6}$ рад.

**Шаг 2. Скорость поворота вектора скорости:**
$$\Omega = \frac{\Delta\varphi}{\Delta t} = \frac{\pi/6}{2} = \frac{\pi}{12}\ \text{рад/с} \approx 0{,}26\ \text{рад/с}.$$
При движении по окружности скорость всегда перпендикулярна радиусу, поэтому она поворачивается так же быстро, как радиус: $\Omega = \omega$.

**Шаг 3. Ускорение:**
$$a_n = v\,\Omega = \frac{\pi v}{6\Delta t} = 0{,}5\cdot\frac{\pi}{12} \approx 0{,}13\ \text{м/с}^2.$$
:::

:::tip Проверка через радиус
$R = \frac{v}{\omega} = \frac{0{,}5}{0{,}262} \approx 1{,}91$ м. Тогда $a_n = \frac{v^2}{R} = \frac{0{,}25}{1{,}91} \approx 0{,}13$ м/с² ✓.
:::

## Задача 4. Спутник

> С какой скоростью должен лететь спутник, чтобы, постоянно «падая» к Земле с ускорением $g$, двигаться по окружности? Радиус орбиты $R = 6400$ км.

  <text class="s" x="300.0" y="88.0">ускорением g, но летит вбок так</text>
  <text class="s" x="300.0" y="106.0">быстро, что «промахивается»</text>
  <text class="s" x="300.0" y="124.0">мимо Земли — и падает по кругу.</text>
  <text class="i tc5" x="300.0" y="160.0">g = v²/R</text>
  <text class="i" x="300.0" y="190.0">v = √(gR) ≈ 8 км/с</text>
</svg>

:::key Идея
«Падает с ускорением $g$» — значит, ускорение спутника $g$ и направлено к центру Земли. Для движения по окружности оно должно равняться центростремительному $\frac{v^2}{R}$.
:::

:::solution Решение
$$\frac{v^2}{R} = g \quad\Rightarrow\quad v = \sqrt{gR} = \sqrt{9{,}8\cdot 6{,}4\cdot 10^6} \approx 7{,}9\cdot 10^3\ \text{м/с} \approx 8\ \text{км/с}.$$
Это **первая космическая скорость**.
:::

:::tip Почему спутник не падает на Землю
Он падает! Каждую секунду он «проваливается» к Земле, но за это время улетает вбок настолько, что поверхность Земли тоже «уходит вниз» (Земля круглая). В итоге расстояние до центра не меняется. Если скорость меньше $\sqrt{gR}$, спутник упадёт. Если больше, орбита станет вытянутой (эллипс), а при скорости больше $\approx 11{,}2$ км/с спутник совсем улетит от Земли.
:::

:::key Идея
Разложим ускорение на касательное (меняет **модуль** скорости) и нормальное (**поворачивает** скорость) — теория, раздел 3.
:::

:::solution Решение по шагам
**Шаг 1. Разложение:**
$$a_\tau = a\cos30^\circ = 10^4\cdot\frac{\sqrt3}{2} \approx 8{,}66\cdot10^3\ \text{м/с}^2,\qquad a_n = a\sin30^\circ = 5\cdot10^3\ \text{м/с}^2.$$

**а)** Модуль скорости меняет только $a_\tau$:
$$\Delta v = a_\tau\,\Delta t = 8{,}66\cdot10^3\cdot10^{-2} \approx 87\ \text{м/с}.$$

**в)** Сначала найдём угловую скорость поворота вектора скорости. Из $a_n = v\,\Omega$:
$$\Omega = \frac{a_n}{v} = \frac{5\cdot10^3}{10^6} = 5\cdot10^{-3}\ \text{с}^{-1}.$$

**б)** Угол поворота за $\Delta t$:
$$\Delta\varphi = \Omega\,\Delta t = 5\cdot10^{-3}\cdot10^{-2} = 5\cdot10^{-5}\ \text{рад}.$$
:::

:::tip Почему можно считать ускорение постоянным
За $10^{-2}$ с скорость изменилась на 87 м/с из $10^6$ м/с — меньше чем на 0,01 %, а направление повернулось на крошечный угол. Значит, все величины за это время почти не менялись, и формулы «как для постоянного ускорения» дают верный ответ.

Бонус: радиус кривизны траектории в этот момент $\rho = \frac{v^2}{a_n} = \frac{10^{12}}{5\cdot10^3} = 2\cdot10^8$ м.
:::

:::warn Типичная ошибка
Писать $\Delta v = a\,\Delta t = 100$ м/с, то есть брать полное ускорение. Модуль скорости меняет только составляющая **вдоль** скорости.
:::
