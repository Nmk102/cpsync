Нужна теория из раздела 6 («Качение без проскальзывания»). В этих задачах работают два инструмента, и полезно уметь оба.

:::key Два инструмента
**1. Сложение движений.** Скорость любой точки тела = скорость центра + скорость вращения вокруг центра:
$$\vec v_X = \vec v_O + (\text{вращательная часть: } \omega\cdot|OX|,\ \perp OX).$$

**2. Мгновенная ось.** Если какая-то точка тела в этот момент неподвижна (точка касания при качении), тело вращается вокруг неё: $v_X = \omega\cdot|PX|$, $\vec v_X \perp PX$.

**Следствие.** Вдоль любого отрезка твёрдого тела скорости (их составляющие, перпендикулярные отрезку) меняются **линейно**. Поэтому у середины отрезка — среднее арифметическое скоростей его концов, а концы стрелок скоростей лежат на одной прямой.
:::

:::solution Решение по шагам
**Шаг 1. Раскладываем движение.** Движение обруча = движение центра $O$ со скоростью $v_O$ + вращение вокруг $O$ с угловой скоростью ω. Вращательная часть у точек $A$ и $B$ равна $\omega R$ и перпендикулярна $AB$, причём у $A$ и $B$ она направлена **в разные стороны**. Скорости $v_A$, $v_B$ тоже перпендикулярны $AB$, поэтому и $v_O$ перпендикулярна $AB$.

**Шаг 2. Находим $v_O$ и $\omega R$.** Пусть $v_B > v_A$ (как на рисунке). Тогда у $B$ вращение «помогает», у $A$ — «мешает»:
$$v_B = v_O + \omega R,\qquad v_A = v_O - \omega R.$$
Складываем и вычитаем:
$$v_O = \frac{v_A + v_B}{2},\qquad \omega R = \frac{v_B - v_A}{2}.$$

**Шаг 3. Точки $C$ и $D$.** У них вращательная часть $\omega R$ перпендикулярна $OC$, то есть направлена **вдоль $AB$**, а $v_O$ — перпендикулярно $AB$, то есть вдоль $CD$. Векторы перпендикулярны, складываем по Пифагору:
$$v_C = v_D = \sqrt{v_O^2 + (\omega R)^2} = \sqrt{\frac{(v_A + v_B)^2 + (v_B - v_A)^2}{4}} = \sqrt{\frac{v_A^2 + v_B^2}{2}}.$$

**Шаг 4. Направление.** Угол φ между скоростью и диаметром $CD$:
$$\tan\varphi = \frac{\omega R}{v_O} = \frac{|v_B - v_A|}{v_A + v_B}.$$
У $C$ и $D$ скорости отклонены от $CD$ в **разные** стороны (у одной вращательная часть смотрит к $B$, у другой — к $A$).
:::

:::tip Проверка
- $v_A = v_B$: обруч движется без вращения, $\tan\varphi = 0$, $v_C = v_A$ ✓.
- $v_A = 0$: обруч катится, $A$ — точка касания. Тогда $v_C = \frac{v_B}{\sqrt2}$, $\varphi = 45^\circ$. По мгновенной оси: $|AC| = \sqrt2 R$, $|AB| = 2R$, $\frac{v_C}{v_B} = \frac{\sqrt2}{2}$ ✓.
- Если бы $v_A$ и $v_B$ были направлены в **разные** стороны, нужно заменить $v_A$ на $-v_A$. Модуль $v_C$ при этом не изменится: $\sqrt{\frac{v_A^2 + v_B^2}{2}}$.
:::

:::key Идея
«Без проскальзывания» = точка катушки, касающаяся доски, движется **вместе с доской**. По рисунку учителя верхняя доска касается **оси** катушки (радиус $r$, точка на $r$ выше центра), а нижняя — **обода** (радиус $R$, точка на $R$ ниже центра).
:::

:::solution Решение по шагам
**Шаг 1. Скорости точек касания** (сложение движений, катушка крутится по часовой стрелке, верх движется быстрее центра):
- верхняя точка (на $r$ выше центра): $v_0 + \omega r$;
- нижняя точка (на $R$ ниже центра): $v_0 - \omega R$.

**Шаг 2. Условие без проскальзывания:**
$$\begin{cases} v_0 + \omega r = v_1, \\ v_0 - \omega R = v_2. \end{cases}$$

**Шаг 3. Решаем.** Вычитаем второе из первого: $\omega(R + r) = v_1 - v_2$:
$$\omega = \frac{v_1 - v_2}{R + r}.$$
Подставляем в первое:
$$v_0 = v_1 - \omega r = v_1 - \frac{(v_1 - v_2)r}{R + r} = \frac{v_1 R + v_2 r}{R + r}.$$
:::

:::tip Проверка
- $v_1 = v_2$: $\omega = 0$, $v_0 = v_1$ — катушка просто едет вместе с досками ✓.
- $v_2 = 0$ (нижняя доска стоит — это просто пол): $\omega = \frac{v_1}{R + r}$. По мгновенной оси (точка касания с полом) верхняя точка касания находится на расстоянии $R + r$: $v_1 = \omega(R + r)$ ✓.
- На рисунке концы стрелок $v_1$, $v_0$, $v_2$ лежат на одной прямой — так и должно быть (следствие из ключевой идеи).
:::

:::warn Типичная ошибка
Перепутать, какой радиус у какой доски, и написать $v_0 = v_1 - \omega R$. Сначала посмотрите на рисунок и подпишите: «верх — $r$, низ — $R$».
:::

:::solution Решение по шагам
**Шаг 1. Скорости колец в точках касания.** Шарик касается внутреннего кольца на радиусе $r_1$ и внешнего — на радиусе $r_2$. Точки колец там движутся со скоростями
$$u_1 = \omega_1 r_1\ (\text{против часовой}),\qquad u_2 = \omega_2 r_2\ (\text{по часовой}),$$
то есть в **противоположные** стороны.

**Шаг 2. Без проскальзывания.** Точки шарика, касающиеся колец, имеют те же скорости, что и кольца.

**Шаг 3. Центр шарика.** Обе точки касания и центр шарика лежат на одном диаметре шарика (он направлен по радиусу подшипника), и центр — его середина. Скорости точек этого диаметра перпендикулярны ему и меняются вдоль него линейно, значит, скорость центра — **среднее** скоростей концов (с учётом знаков). Примем направление «по часовой» за плюс:
$$v = \frac{u_2 + (-u_1)}{2} = \frac{\omega_2 r_2 - \omega_1 r_1}{2},\qquad |v| = \frac{|\omega_1 r_1 - \omega_2 r_2|}{2}.$$
:::

:::tip Проверка и бонус
- Если $\omega_1 r_1 = \omega_2 r_2$, центры шариков стоят на месте (шарики крутятся «на месте») ✓.
- Если внешнее кольцо неподвижно ($\omega_2 = 0$), то $v = \frac{\omega_1 r_1}{2}$: шарик катится по неподвижному кольцу, и его центр движется вдвое медленнее точки касания с подвижным кольцом. Это как колесо: центр едет со скоростью $v_0$, верх — $2v_0$ ✓.
- Угловая скорость самого шарика: $\omega_ш = \frac{u_1 + u_2}{2r_ш} = \frac{\omega_1 r_1 + \omega_2 r_2}{r_2 - r_1}$, где $2r_ш = r_2 - r_1$.
:::

:::solution Решение по шагам
**Шаг 1. Из чего состоит ускорение точки обода** (теория, раздел 6.4):
- $\vec a_0$ — вместе с центром, вперёд;
- $\vec a_\tau$ — касательное от разгона вращения: $a_\tau = \varepsilon R = a_0$ (из условия качения $a_0 = \varepsilon R$), направлено как скорость точки при вращении вокруг центра;
- $\vec a_n$ — к центру, $a_n = \omega^2 R$.

Колесо катится вперёд (вправо), значит, крутится по часовой стрелке. При таком вращении относительно центра верх движется вперёд, низ — назад, задняя точка — вверх.

**Шаг 2. Точка $C$ (низ).** $\vec a_0$ — вперёд, $\vec a_\tau$ — назад, они уничтожаются. Остаётся $a_n = \omega^2 R$ вверх. Условие задачи: $|a_C| = a_0$, значит, **в этот момент** $\omega^2 R = a_0$.

**Шаг 3. Точка $A$ (верх).** Вперёд: $a_0 + a_\tau = 2a_0$. Вниз (к центру): $a_n = a_0$.
$$a_A = \sqrt{(2a_0)^2 + a_0^2} = \sqrt5\,a_0.$$

**Шаг 4. Точка $B$ (задняя).** Вперёд: $a_0$ (поступательное) $+\ a_n = a_0$ (к центру — тоже вперёд!) $= 2a_0$. Вверх: $a_\tau = a_0$.
$$a_B = \sqrt{(2a_0)^2 + a_0^2} = \sqrt5\,a_0.$$
:::

:::warn Где чаще всего ошибаются
1. Считают, что у точки касания ускорение ноль («она же неподвижна»). Неподвижна — это про **скорость**; ускорение у неё $\omega^2 R$ вверх.
2. Забывают, что у задней точки $a_n$ направлено к центру, то есть **вперёд**, и складывается с $a_0$.
:::

:::solution Решение по шагам
**Шаг 1. Мгновенная ось.** Катушка катится без проскальзывания, поэтому точка касания со столом $P$ неподвижна. Катушка вращается вокруг $P$ с некоторой ω.

**Шаг 2. Связь с нитью.** По рисунку нить сходит с **низа** внутреннего цилиндра горизонтально. Точка схода находится на высоте $R - r$ над $P$, и её скорость горизонтальна: $\omega(R - r)$. Нить нерастяжима, поэтому конец нити движется так же быстро:
$$u = \omega(R - r)\quad\Rightarrow\quad\omega = \frac{u}{R - r}.$$

**Шаг 3. Скорость оси** (ось на расстоянии $R$ от $P$):
$$v = \omega R = \frac{uR}{R - r},$$
направлена **в ту же сторону, что** $\vec u$.

**Шаг 4. Скорость точки $A$** (на расстоянии $2R$ от $P$):
$$v_A = \omega\cdot 2R = \frac{2uR}{R - r}.$$

**Шаг 5. Ускорение точки $A$.** $u$ постоянна, значит, ω и $v$ постоянны: катушка катится равномерно. В инерциальной системе оси точка $A$ равномерно вращается по окружности радиуса $R$:
$$a_A = \omega^2 R = \frac{u^2 R}{(R - r)^2},$$
направлено **к оси $O$** (вниз).
:::

:::tip Проверка и интересное следствие
- $r \to 0$ (нить у самого стола): $v \to u$ — катушка едет как нить ✓.
- $v > u$: ось катушки движется **быстрее** руки, поэтому нить наматывается на катушку, и катушка «догоняет» руку.
- Если бы нить сходила с **верха** внутреннего цилиндра (высота $R + r$ над $P$), было бы $v = \frac{uR}{R + r} < u$.
:::

:::warn Типичная ошибка
Считать $a_A = \omega^2\cdot 2R$ («вращение вокруг $P$»). Мгновенная ось даёт только скорости, а ускорение — из системы оси катушки.
:::
