Юнит *Unit 2 — Newton's laws*. Почти все задачи динамики решаются **одним и тем же алгоритмом** — его и нужно довести до автоматизма. Ниже теория в том объёме, который нужен для домашек 6–7 и олимпиадных задач уровня TLF.

## 1. Три закона Ньютона

:::def Первый закон (закон инерции)
Существуют **инерциальные системы отсчёта** (*inertial frames of reference*): в них тело сохраняет скорость (покоится или движется равномерно и прямолинейно), если сумма действующих на него сил равна нулю.
:::

:::def Второй закон
$$m\vec a = \sum \vec F_i$$
Векторная сумма **всех** сил, действующих на тело, равна массе, умноженной на ускорение. В задачах пишем его **в проекциях на оси** — для каждого тела отдельно.
:::

:::def Третий закон
Тела действуют друг на друга с силами, **равными по модулю и противоположными по направлению**: $\vec F_{12} = -\vec F_{21}$. Эти силы приложены **к разным телам**, поэтому никогда не «сокращаются» в уравнении для одного тела.
:::

## 2. Какие бывают силы

| Сила | Обозначение | Направление | Модуль |
|---|---|---|---|
| тяжести (*gravity, weight force*) | $m\vec g$ | вертикально вниз | $mg$ |
| реакции опоры (*normal force*) | $\vec N$ | **перпендикулярно** поверхности, от опоры | «сколько нужно» — находится из уравнений |
| натяжения (*tension*) | $\vec T$ | **вдоль нити** к точке подвеса | из уравнений; в невесомой нити одинаково по всей длине |
| упругости (*spring force*) | $\vec F_{упр}$ | против деформации | $k\,|x|$ — закон Гука |
| трения скольжения (*kinetic friction*) | $\vec F_{тр}$ | против скорости относительно поверхности | $\mu N$ |
| трения покоя (*static friction*) | $\vec F_{тр}$ | против возможного движения | $0 \le F \le \mu_s N$ — «сколько нужно» |

:::warn Три частые ошибки
1. **$N = mg$ — не всегда!** Только когда тело лежит на горизонтальной опоре и ускорение по вертикали равно нулю. На наклонной плоскости $N = mg\cos\alpha$, в ускоряющемся лифте $N = m(g + a)$, на вогнутом мосту $N = m\left(g + \frac{v^2}{R}\right)$.
2. **$T = mg$ — тоже не всегда:** только если груз висит неподвижно (или движется равномерно).
3. **Вес $P$ — это не сила тяжести.** Вес — сила, с которой тело давит на опору или тянет подвес. По третьему закону $P = N$. В лифте, ускоряющемся вверх, вес больше $mg$ (перегрузка), при свободном падении равен нулю (невесомость).
:::

## 3. Алгоритм решения задач динамики

:::key Пять шагов
1. **Выделите тела** и для каждого нарисуйте **все силы** (*free-body diagram*): тяжесть + по одной силе на каждое соприкосновение (опора, нить, пружина, клин, стена). Сил «от движения» не бывает.
2. **Выберите оси**: удобно одну ось — вдоль ускорения.
3. **Запишите второй закон в проекциях** для каждого тела.
4. **Добавьте кинематические связи** (*constraints*): нерастяжимая нить → одинаковые по модулю ускорения; клин → связь через $\tan\alpha$; подвижный блок → ускорение груза вдвое меньше ускорения конца нити.
5. **Решите систему** и **проверьте**: размерность, знак, предельные случаи ($\alpha \to 0$, $m_1 = m_2$, $a \to 0$ и т. п.).
:::

Человек массой $m$ в лифте, который движется с ускорением $a$ **вверх**. Силы: $N$ вверх, $mg$ вниз. Ось вверх:
$$N - mg = ma \;\Rightarrow\; N = m(g + a).$$
Вес $P = N = m(g+a) > mg$ — перегрузка. Если лифт ускоряется вниз с ускорением $a$: $P = m(g - a)$. При $a = g$ (свободное падение) $P = 0$ — **невесомость**.

Два груза $m_1 > m_2$ на нити через невесомый блок без трения. Нить нерастяжима → ускорения одинаковы по модулю: $m_1$ вниз, $m_2$ вверх.
$$\begin{cases} m_1 a = m_1 g - T \\ m_2 a = T - m_2 g \end{cases} \;\Rightarrow\; a = \frac{m_1 - m_2}{m_1 + m_2}\,g, \qquad T = \frac{2m_1 m_2}{m_1 + m_2}\,g.$$
*Проверка:* при $m_1 = m_2$ получаем $a = 0$, $T = mg$ ✓; при $m_2 \to 0$ — $a \to g$, $T \to 0$ ✓.

## 4. Наклонная плоскость

Тело на гладкой наклонной плоскости с углом $\alpha$. Оси: $x$ — вдоль склона вниз, $y$ — перпендикулярно.
$$y:\; N - mg\cos\alpha = 0 \;\Rightarrow\; N = mg\cos\alpha; \qquad x:\; ma = mg\sin\alpha.$$
С трением: $ma = mg\sin\alpha - \mu mg\cos\alpha$. Тело покоится, если $\tan\alpha \le \mu$.

:::tip Если плоскость (клин) сама движется
Тогда тело **не обязано** двигаться вдоль склона в «покоящейся» системе, и $N \ne mg\cos\alpha$. Нужно писать второй закон для **обоих** тел и добавлять кинематическую связь — см. задачи 2 и 5 домашки 7.
:::

## 5. Кинематические связи

| Ситуация | Связь |
|---|---|
| два тела на нерастяжимой нити | $a_1 = a_2$ (по модулю, вдоль нити) |
| подвижный блок, на котором висит груз | $a_{груза} = \dfrac{a_{конца\ нити}}{2}$ |
| стержень в вертикальной направляющей опирается на клин с углом $\alpha$, клин едет горизонтально | $a_{стержня} = a_{клина}\tan\alpha$ |
| клин с углом $\alpha$ при вершине раздвигает два бруска | $a_{брусков} = a_{клина}\tan\frac{\alpha}{2}$ |

Как выводить такие связи: представьте, что клин сдвинулся на маленькое $x$. На сколько при этом сдвинется второе тело? Отношение перемещений = отношению скоростей = отношению ускорений.

## 6. Движение по окружности

Если тело движется по окружности радиуса $R$ со скоростью $v$, у него есть **центростремительное ускорение** $a_n = \dfrac{v^2}{R}$, направленное к центру. Во втором законе это обычное ускорение:
$$\sum F_{к\ центру} = \frac{mv^2}{R}.$$
- Нижняя точка **вогнутого** моста (центр сверху): $N - mg = \dfrac{mv^2}{R} \Rightarrow N = m\left(g + \dfrac{v^2}{R}\right)$.
- Верхняя точка **выпуклого** моста (центр снизу): $mg - N = \dfrac{mv^2}{R} \Rightarrow N = m\left(g - \dfrac{v^2}{R}\right)$; при $v^2 = gR$ машина отрывается.

:::tip Относительное движение (для задачи 4 домашки 7)
Если груз качается на нити, привязанной к **движущейся** тележке, то центростремительное ускорение груза относительно тележки считается по **относительной** скорости: $\dfrac{(v_{груза} - v_{тележки})^2}{L}$. Полное ускорение груза = ускорение тележки + относительное.
:::

## 7. Проверь себя

:::task 1. Книга лежит на столе. Какая сила — пара к силе тяжести книги по третьему закону Ньютона?
:::answer
Сила, с которой **книга притягивает Землю** (приложена к Земле, направлена вверх). Реакция стола $N$ — **не** пара к $mg$: обе силы приложены к книге.
:::
:::

:::task 2. Груз 5 кг поднимают на верёвке с ускорением 2 м/с². Найдите натяжение ($g = 9{,}8$ м/с²).
:::solution
$T - mg = ma \Rightarrow T = m(g + a) = 5 \cdot 11{,}8 = 59$ Н.
:::
:::

:::task 3. Автомобиль 1000 кг проезжает нижнюю точку вогнутого моста радиусом 50 м со скоростью 10 м/с. С какой силой он давит на мост?
:::solution
$N = m\left(g + \frac{v^2}{R}\right) = 1000\,(9{,}8 + 2) = 11\,800$ Н. По третьему закону с такой же силой автомобиль давит на мост.
:::
:::

:::task 4. В машине Атвуда $m_1 = 3$ кг, $m_2 = 1$ кг. Найдите ускорение и натяжение нити ($g = 10$ м/с²).
:::solution
$a = \frac{3-1}{4}\cdot 10 = 5$ м/с²; $T = \frac{2 \cdot 3 \cdot 1}{4}\cdot 10 = 15$ Н.
:::
:::
