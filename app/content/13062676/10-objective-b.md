Сейчас этап **Objective B — Applying the skills**. Задачи: выбрать **один ATL-навык для Learning Goal (LG)** и **один для Product Goal (PG)**, применять их и **собирать доказательства** в Process Journal (папка *Objective B — Evidence*, внутри — папки по каждому ATL).

## 1. Десять кластеров ATL

| Категория | Кластер | Пример навыка |
|---|---|---|
| Communication | Communication | использовать разные медиа; получать обратную связь |
| Social | Collaboration | давать и принимать фидбек, работать в команде |
| Self-management | Organization | планировать, управлять временем, вести журнал |
| | Affective | справляться с неудачами, концентрироваться |
| | Reflection | оценивать свой прогресс, менять стратегию |
| Research | Information literacy | искать и проверять источники, вести библиографию |
| | Media literacy | критически оценивать медиа, сравнивать источники |
| Thinking | Critical thinking | анализировать данные, плюсы и минусы, тестировать |
| | Creative thinking | генерировать идеи, прототипы, эскизы |
| | Transfer | применять знания из других предметов |

## 2. Как выбрать навык

Хороший выбор — навык, который вы **реально** используете **чаще всего** и для которого легко собрать доказательства.

Пример для проекта «сайт для дуэлей на Codeforces» (подставьте свои формулировки):

| Цель | ATL | Почему подходит | Доказательства |
|---|---|---|---|
| **LG** — научиться веб-разработке (HTML/JS, работа с API) | **Information literacy** | искать документацию, учебники, сравнивать источники, выбрать подход | таблица источников (что, где, насколько надёжно), конспекты, ссылки, скриншоты документации Codeforces API |
| **PG** — работающий сайт для дуэлей | **Critical thinking** (тестирование и отладка) или **Organization** (план, этапы) | проверка гипотез, поиск ошибок, принятие решений | лог ошибок «проблема → причина → решение», история коммитов на GitHub, таблица тестов, план с дедлайнами |

:::warn Важно
Учитель просил «**less is more**»: в отчёте — **один** ATL для LG и **один** для PG. Собирать доказательства можно по нескольким, но писать — по одному на каждую цель.
:::

## 3. Что считается доказательством

| Кластер | Возможные доказательства |
|---|---|
| Communication | переписка с супервайзером, вопросы на форумах, ответы |
| Collaboration | фидбек от друзей-тестировщиков, договорённости |
| Organization | план, календарь, to-do, таймлайн, история задач |
| Affective | записи о неудачах и как справился, распорядок для концентрации |
| Reflection | самооценки, «что получилось / что нет», обновления статуса |
| Information literacy | таблица источников, аннотированная библиография |
| Media literacy | сравнение источников, диаграммы Венна |
| Critical thinking | таблицы плюсов и минусов, анализ данных, результаты тестов |
| Creative thinking | эскизы, прототипы, mind maps |
| Transfer | список знаний из других предметов, которые пригодились (у вас: C++ и алгоритмы → JavaScript) |

**Формат любой**: скриншоты, фото, голосовые, документы. Главное — **дата** и **короткая подпись**: что это и какой навык показывает.

## 4. Как писать в отчёте (критерий B)

**Bi — для Learning Goal:**
1. **Назовите** кластер и конкретный навык.
2. **Опишите**, как вы его применяли — шаги.
3. **Объясните, почему** это помогло достичь цели (связь навык → цель).
4. **Подтвердите** примером или доказательством (скриншот прямо в тексте).

**Bii — для Product Goal** — так же, только связь с продуктом.

Шаблон абзаца:
> *To achieve my learning goal, I developed **information literacy skills**, specifically **evaluating sources**. I compared three tutorials on the Codeforces API (Figure 3) and chose the official documentation because… This helped me reach my learning goal because… For example, …*

:::tip Чек-лист Objective B
- [ ] в Process Journal есть папка *Objective B — Evidence* с подпапками по ATL;
- [ ] каждый файл подписан и датирован;
- [ ] для LG и PG выбрано по **одному** ATL, указана категория и конкретный навык;
- [ ] в отчёте: «как применял» + «почему помогло» + доказательство на каждое утверждение.
:::
